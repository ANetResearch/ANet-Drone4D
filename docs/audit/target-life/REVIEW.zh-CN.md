# 场景目标系统：本次部署与验收

部署入口：<http://127.0.0.1:28660/world/synthcity>。创建 **T13 七种车型与六类目标（实验）**，可查看 12 人、7 辆不同车型、2 犬、2 架巡检无人机、1 台叉车和 3 个固定设施。T9 为 30 实体城市生活；T10/T11 是两份已保存的 DeepSeek 定制案例。已有旧沙盒保留原配置，需创建新模板实例才能查看最新群体。

## 可以检查的功能

- 在“识别物”中选择目标：查看稳定 ID、资产、当前活动、目的地、等待原因和移动进度；车辆可编辑车牌和元数据。替换外观不得超过已准入的路线车身尺寸。
- 在“场景生活生成器”中选择人口、车型、其他类别和 seed。生成预览先完成 1500 秒准入，再显式应用；应用会重置沙盒。相同锁定输入与 seed 得到相同配方，车型勾选顺序不改变结果。
- 观察跨街区的设施到访、通勤/购物、进出设施、车辆停靠、路权等待和避让。室内使用入口占用与隐藏状态表达，目标 ID 保留。
- 全部实体每 0.1 秒参加同一个行为步。停留须有活动原因；不按相机是否看见或目标总数轮流激活。生成预览和模型等待期间，已运行的世界继续推进。

## 本轮浏览器复测修复

- 小窗口隐藏视口时，启动阶段仍允许必要渲染；启动完成才暂停被遮挡的画布，世界时钟不暂停。
- 资产失败可显式重试，不重置目标身份，也不逐帧重复请求；同时最多加载两组模型，减少首次加载的网络竞争。
- 近看目标/查看路线自动切回小窗口视口；近看观察相机支持跟随目标，人工操作或进入设施后退出。
- 生活活动卡片不再显示旧 T8 的“没有车辆路权”说明；行进与等待不再显示误导的 0 秒剩余时间。
- 两次早期实时连接探测发生停顿；限制加载并发后的 90 秒探测完成，无断线，最大相对时钟偏差 0.87 秒。尚不能据此宣称所有网络问题都已解决。

模型检查入口：识别物详情 → **近看并跟随目标**；车辆另有 **近看前车牌**。这只是观察相机，不给 agent 增加识别能力或控制无人机。拖动画面、切换视角或目标进入设施后退出跟随；车牌近景保留观察方向，车辆转弯后可能需重新对准。
