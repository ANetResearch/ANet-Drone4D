## 4. 偏差与原因

| 偏差 | 原因 |
|---|---|
| 组件安装 44 个而不是"全量" | 任务书写"建议全量"，M15 PRD §6.1 规定 D1 为 44 个、禁止 `--all`，并列出 8 个禁用组件；按 PRD 执行 |
| z 层级 token 放在 `styles/layout.css`，取 AWR-14 §2.1 的层级表 | AWR-15 草案与 AWR-14 取值不同，层级语义属于布局，按 AWR-14 |
| 图标清单 E 组重复的 `cmd.search` 改名 `cmd.search-area` | AWR-15 §7.6 表中两处同名，check-icons 要求 key 唯一 |
