## 1 做了什么

### 1.1 文档站工程

- 仓库根新建 `docs-site/`：`zh_CN/` 与 `en/` 两套 MyST Markdown 源，19 个文档名一一对应；公共配置、扩展、模板与静态资源放在 `docs-site/_shared/`。
- 主题为 sphinx-rtd-theme 3.1.0，左上角为 Agent Network 标志（`apps/web/public/brand/anet-logo.svg` 的同一文件，sha256 与品牌锁一致）；窄屏顶栏同样显示标志。
- 配色：`drone4d.css` 开头的 `:root` 块是文档站唯一的颜色定义处，取值与 `apps/web/src/styles/theme.css` 的 ANet Graphite 原始层一致（13 阶冷灰与 5 阶红），其余规则只引用变量。
  覆盖了 RTD 的蓝色侧栏头、链接、代码、提示框、表格、按钮、窄屏顶栏与浮层；代码高亮改为灰阶（Pygments `bw` 加变量配色）；表格为 lieflat 风格（细横线、无竖线、无斑马纹）。
  动效取 transitions.dev 的时长与缓动（150 ms、250 ms，`cubic-bezier(0.22, 1, 0.36, 1)`），并遵循 `prefers-reduced-motion`。
- 图标：RTD 自带的 FontAwesome 字形（主页、在 GitHub 上编辑、菜单、上下页、提示框、目录展开、标题锚点、浮层箭头）全部替换为由 lucide@1.48.0 IconNode 生成的遮罩图标
  （与 Web 端 morphicons 注册表同一几何来源），生成器 `docs-site/_shared/tools/gen-icons.mjs`；复制按钮图标同样替换。
- 语言与版本浮层：静态实现 Read the Docs 风格的 `rst-versions`（侧栏底部，语言 zh-cn 与 en、版本 latest、项目链接），链接到另一语言的同一页面；支持键盘操作与 Esc 关闭。
  在 Read the Docs 上构建时（`READTHEDOCS=True`）不输出，由平台浮层代替。另输出 hreflang 备用链接。
- URL 布局与 RTD 一致：`_build/html/{en,zh-cn}/latest/`，根页 `index.html` 按浏览器语言跳转（`zh*` 到 zh-cn，其余到 en），无脚本时回退到 en。
- 自有扩展：
  - `drone4d_api`：`drone4d-endpoints` 指令在构建时读取 `packages/contracts/rest/sandbox.openapi.snapshot.json` 与 `openapi.snapshot.json` 生成分组端点表
    （沙盒 82 个操作：编号、方法、路径、说明、鉴权、优先级；运行时 82 个操作：方法、路径、说明）。英文说明与运行时接口的中英文说明在 `api_summaries.json`；
    快照新增操作而缺少说明时告警，`-W` 下构建失败，保证端点表与快照同步。
  - `drone4d_site`：两种语言的文档名一致性检查（缺页即告警失败）、浮层链接计算，以及中文软换行处理（源文件中的换行与中日韩字符或全角标点相邻时删除，
    避免浏览器把换行显示为多余空格；中西文之间保留空格）。
- 中文全文检索使用 jieba 分词（固定在 requirements.txt）。

## 4 偏差

1. **端口偏移 600 的实现方式。** `net.port_offset` 的取值范围为 0 至 31（端口加 10·k），无法表达 600。临时克隆中以 `.env.local` 设置
   `AWR_PORT=8600`、`AWR_STATIC_PORT=8601`、`AWR_SANDBOX_PORT=8602`，并在克隆的 `configs/runtime.yaml` 中把总线汇合点改为 8047、vite 改为 5773
   （总线与 vite 没有对应的环境变量）。这些改动只存在于已删除的临时克隆中，文档输出中的端口已还原为默认值并在页首说明。
2. **钉核。** 第 1 次 `make run` 时同机另一实例的 sim-core 也钉在 1 号核，本次 sim-core 心跳超时被热备用连续接替 5 次；随后在临时克隆的 `.env.local`
   中加入 `AWR_CPU_PIN=off` 重跑。文档以第 2 次运行的输出为准，并把第 1 次的现象与处理写入排错一节。
3. **SDK 示例的两处调整。** 为得到可复现的输出，示例在加机后轮询到电量字段出现再读状态；会话概况改为用列表计数（见 5.2）。示例设置 `timeout_s=30`（见 5.1）。
4. **`.gitignore`。** 任务要求为 `.venv-docs` 追加一行；既有规则 `.venv-*/` 已覆盖它，因此追加的唯一一行为构建输出 `/docs-site/_build/`。
5. **Read the Docs 配置为两份。** RTD 的翻译以独立项目实现，各项目只读一个配置文件；根目录 `.readthedocs.yaml` 对应英文主项目，
   `docs-site/zh_CN/.readthedocs.yaml` 对应中文翻译项目（需在 RTD 项目设置中指定路径）。
6. **图标。** 为符合"图标只用 morphicons"的约束，RTD 主题的 FontAwesome 字形改为 lucide 几何的遮罩图标；主题自带的字体文件仍随构建输出（主题要求），未被页面使用的部分不影响显示。
7. **新增依赖 jieba。** 用于中文全文检索分词，只在 `.venv-docs` 中。
8. **新增 `docs-site/README.md`。** 面向维护者的目录说明与编写约定，不参与 Sphinx 构建。
9. **未上传。** 按任务要求，`publish.sh` 只准备目录并打印命令；线上 `https://docs.agentnetwork.org.cn/drone4d/` 尚未发布，浮层中的"文档托管于"链接在发布后生效。

## 5 发现的问题与遗留

1. **SDK 排队超时（建议修复，tools/sdk 所有者）。** `Sandbox()` 缺省 `timeout_s=10`，而排队长轮询 `GET /queue/{ticket}?wait_s=25` 单次最长 25 s，
   实际排队时 httpx 以 `ReadTimeout` 失败（本次真实复现：本机 `max_sessions=1`，前一会话未结束时第二个 `create()` 失败）。`wait_ready()` 的 `wait_s=10`
   与 10 s 超时也处于临界。建议 SDK 对长轮询请求单独设置 `timeout = wait_s + 5`。文档中暂以 `timeout_s=30` 作为用法说明。
2. **会话概况的计数滞后。** 会话刚进入 READY 时，`GET /sessions/{sid}` 的 `usage` 偶尔为全 0（同一模板另两次为 7、2），而列表接口已能返回 7 架机与 2 个识别物；
   建议 sandbox-pool 在 READY 前填充 `usage`。
