### 1.3 文案

全部 `landing.*` 文案中英文重写，遵循 docs/05 §7.10：名词短语与陈述句，按钮为动宾结构，无感叹号、无口号（删除“从真实世界，到无人机集群。”与 “Reality in, swarms out.”），数字附条件，英文为 sentence case。中文定位语用零宽空格标出断行位置并配合 `word-break: keep-all`，手机上断为“真实世界驱动的 / 多智能体无人机 / 四维仿真平台”，桌面单行显示；“30 min”“120 min”使用不换行空格。

### 1.4 体素滚动背景

`LandingVoxel.tsx`（落地页分块内，只负责挂载）在空闲回调中动态加载 `voxelField.ts`（独立懒加载分块，不进入首屏静态闭包）：

- 场景：程序生成的体素城市街区（6 x 6 地块、一格街道，2 x 2 地块共用高度，中心塔楼），随滚动由中心向外逐层生长；红色扫描带横扫街区并在其后留下较亮的接缝；七机 V 形编队沿 8 字航线飞行，两架无人机环绕塔楼。滚动推进生长、扫描、相机方位与缩放，时间只提供缓慢漂移。
- 渲染：WebGL2 每帧一次 `drawArraysInstanced`（36 顶点立方体 x 每格一个实例，加 9 架无人机）；只用普通 uniform，不用 uniform block、纹理或浮点渲染目标；体素接缝由片元着色器以 `fwidth` 抗锯齿绘制。无 WebGL2 时退回 Canvas2D 等距渲染（较小网格），两者都不可用时保留 CSS 网格底纹（静态）。
- 颜色：启动时读取主题 token（g900、g850、g800、g700、g500、r500），源码无颜色字面量；首屏不透明度 0.9（手机 0.6、平板 0.62），进入正文后降到 0.36（手机 0.3、平板 0.32），无人机再乘 0.85，保证低对比不干扰阅读。
- 性能档：桌面 40 x 40 格、上限 60 fps、DPR 上限 2、MSAA；平板 30 x 30 格、30 fps；手机 22 x 22 格、30 fps、DPR 上限 1.5；后备缓冲上限 4 Mpx；识别到软件光栅（SwiftShader、llvmpipe 等）时降为 20 fps、DPR 1。
- 节能：页面隐藏、画布离开视口时暂停；9 s 无滚动或指针输入后停止渲染，滚动、指针移动、尺寸变化时恢复；`prefers-reduced-motion` 时只渲染一帧静止画面（滚动不再重绘），分区直接显示，不做平滑滚动与入场动效。WebGL 上下文丢失时暂停，恢复时重建资源。
- 测试钩子：`data-voxel-mode`（webgl2、canvas2d、static）、`data-voxel-state`（running、idle、paused、still）、只读属性 `voxelFrames`。

### 1.5 动效与组件

- 动效全部取 transitions.dev token：首屏沿用 `brand-enter`；分区用“texts reveal”配方的 `--stagger-dur`、`--stagger-distance`、`--stagger-ease`，只动 opacity 与 transform（不在 WebGL 画布上方做模糊）；背景画布以 `--duration-very-slow` 淡入。
- 组件只用 shadcn（Button、Badge、Sheet、Separator、Table、ToggleGroup），图标只用 morphicons 注册表键（新增使用 `nav.menu`、`close`、`copy`、`check`、`link`、`data.file`、`chev.right` 等既有键），表格为 lieflat（`data-lf-table`），颜色只用 token，层级只用 `--z-*`。

### 1.6 移动端适配

- 断点：手机 < 768、平板 768 至 1279、桌面 >= 1280 CSS px；页面左右留白 16 px（手机）与 24 px。
- 手机主操作纵向排列、整宽 44 px；平板与手机上全部可交互元素 >= 44 x 44 CSS px（页脚链接、引用切换与复制、菜单项均已处理）；BibTeX 在卡片内换行或滚动，不撑宽页面。
- 图片：横幅 `fetchPriority="high"`，其余全部 `loading="lazy"`、`decoding="async"`，均写明原始宽高与 `sizes`，无布局偏移。

## 4. 偏差与遗留

1. **修改了 `vite.config.ts`**（任务文件清单之外，属于必要修改）。Sheet 依赖 Base UI Dialog 的 store，后者依赖 `use-sync-external-store`；原配置把该包分到 `state` 组，首页首屏会多出 `state` 分块，违反 ADR-083 与部署测试的四分块约束。处理为：把这个 React 官方 shim 并入 `react` 组，`state` 组只保留 zustand；同时把首页新增模块、`sheet.tsx` 与 `lucide-compat.tsx` 纳入 `LANDING_MODULES`。应用路径与 `/sandbox/api` 的行为不变（闭包已核对）。
2. **Agent Swarm 标为“已交付”**：任务给出的已交付清单中没有这一项，但 V0.1 已交付进程内 Mock ANet 的能力发现与委派（S3 端到端通过），因此标为已交付，并在说明中写明“以 Mock ANet 运行，公开站未启用”，不夸大为真实 ANet（真实 ANet 列在路线的 V1.0）。
3. **设计文档链接**仍指向 `DEMO_DOCS_URL`（GitHub `docs/` 目录）。Sphinx 文档站 `docs.agentnetwork.org.cn/drone4d/` 未确认上线，且该常量在 `lib/demo.ts`（不属本任务），待文档站上线后由负责方统一切换。
4. **动图未重新压缩**：README 中唯一的动图 `demo-flight.webp`（960 x 540，200 帧，4.6 MB）首页已展示且为懒加载，由构建插件从 `docs/media` 复制，未新增图片文件。
5. **桌面头部的小尺寸控件**（导航、语言切换、GitHub）高度 24 至 32 px，面向鼠标操作；触控目标 >= 44 px 的要求在 1280 px 以下全部满足，用例只在平板与手机上断言。
6. **Inter 字体的连字符**在大字号下两侧留白较宽，这是字体本身的字形，与全站一致，未做处理。
7. **未部署**：公开站仍运行 v0.2.0 的首页；上线需按 `tools/deploy/emax/` 流程重新打包发布。
8. **未覆盖的用户反馈**：本轮用户提出的“切换城市时 synthcity 的目标物、视野与感知范围被带到其他地图”以及“其他地图加入模拟监测任务与目标物”，属于世界、图层与 store 代码，由 W1/W2 任务负责，本任务按约定未修改相关代码。
9. Playwright 在 Chromium 中模拟 iPhone 与 iPad（本机未安装 WebKit），Safari 的实际表现需在真机上抽查；软件光栅环境下背景以 20 fps 运行，真实 GPU 设备上为 60 fps（桌面）或 30 fps（平板与手机）。

本地服务：截图与用例使用自起的静态服务（端口 9173、9174 及 M06 测试服务器的随机端口），结束后均已关闭，无残留进程。
