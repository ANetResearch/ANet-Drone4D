## 1. 评审方法

1. 自动检查：copy-lint 严格模式（缺省发布面与 `tools/lint/copy-lint.scope.json` 追加范围）、REL-09、lint 自测，以及 `tests/e2e/test_release_copy.py` 与 `tests/d3/copy/test_copy_scope.py`（合计 38 例通过）。
2. 机检清单第 1 条：逐对比较 D3 中文与英文词典的键集合与 ICU 参数名；扫描 78 个 D3 组件与路由文件（`ui/lab/**`、`app/lab-public/**`、`app/routes/lab*`）中注释以外的中文字面量与英文界面字面量；把组件中 `t()` 引用的 667 个静态键与 37 个动态前缀对照词典，确认没有缺键（缺键在界面上显示为键名）。
3. 人工通读：逐条阅读全部 D3 界面字符串（中文 865 条、英文 865 条，含应用主词典中的 139 条 `lab.*` 键），对照 §21.15.2 术语表、§21.15.4 状态显示名、§21.15.5 消息模板与 §7.10 交付称谓表；按页面阅读组件，确认字符串的呈现位置（标题、空状态、错误、确认对话框、页脚）。
4. lint 无法判定、本次人工重点检查的项目：界面中的交付称谓（D1 至 D4）、跨分片与跨语言的术语一致性、消息模板符合度、内部编号与主机名、英文语法。
5. 发布面复核：两份 README 的 V0.3 段落与许可节、落地页路线图、OpenAPI 快照标题与描述、GitHub 仓库线上 About 与 topics（2026-10-21 UTC 经 GitHub 公开 API 只读获取）。

## 3. 评审清单逐条结论（AWR-14 §21.15.9）

1. 中英文双份与键名：9 对词典（6 个 lab 分片、公开构建外壳、样例页、主词典 `lab.*`）键集合完全一致，各 865 条；9 处参数差异均为英文 ICU 复数写法（`{n, plural, ...}`），参数名一致；英文词典中的中文只有语言切换按钮 `lab.public.lang`（显示目标语言名称）。D3 组件中注释以外没有中文字面量与英文界面字面量（仅 `sha256:…`、`MODE=eval` 两处技术示例占位符）。键名符合 §13.7 的 `<域>.<对象>.<属性>`。组件引用的键全部存在；`lab.worlds.openEvents` 未被引用（W-13）。结论：通过。
2. 空状态、错误与确认对话框：运行取消与重试对话框、空状态（`lab.runs.empty`、`lab.events.empty`、`lab.board.empty` 等）与服务端错误（115、305、694、`lab.reason.*`、`{code} {name}`）符合 §21.15.5 模板。例外：会话失效提示缺原因码、原型榜条目详情不可用时缺"可以做什么"、公开样例视频加载失败缺"可以做什么"（W-07）；英文取消对话框为绕开 lint 误报偏离模板原文（W-06）。结论：须改正。
3. 数字与比较：D3 页面没有性能或精度宣称；出现的数字均为参数、阈值或带单位的实测值（例如"组件约 49 MB""单片 64 MB 上限""采样 250 Hz""不超过 1 mm"），无需另附硬件条件；没有"首创"类比较（COPY-08 为 0）。结论：通过。
4. 称谓：中文"沙盘"只出现在 `lab.*` 键与"事件沙盘"中；没有以主版本号 2 指代下一大版本的称谓；物理档、观测档与运行状态用语符合术语表。例外：界面字符串中出现交付称谓 D2、D3（W-01，§7.10 使用规则 1），英文"UAV"术语不统一（W-04），产品名 Interactive Sandbox 大小写（W-09），角色名与术语表不一致（W-03），中文界面夹用英文 Run（W-02）。结论：须改正。
5. 许可与署名：世界详情页"许可与署名"页签显示许可、原作者与来源、修改说明与派生来源（OSM ODbL、DEM 署名来自世界清单）；公开构建页脚在每个页面（含样例下载区）显示署名与许可文件链接；数据集页属 P3（不适用）。`README.md` 与 `README.zh-CN.md` 的许可节尚无 D3 世界资产署名（W-14，V0.3 发布前须补）。结论：D3 页面通过，README 发布前补齐。
6. copy-lint：严格模式 0 error、0 warning，基线例外与放行项均为 0。结论：通过。
