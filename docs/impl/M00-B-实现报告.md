### 1.2 代码生成

- `tools/contracts/contracts_lib.py`：规范 JSON（键排序、无空白、ECMAScript 数字格式，与 JS 端逐字节一致）、`layout_id`（规范 JSON 的 sha256 取前 4 字节小端）、单布局 hash8、AWR-17 §10.3 布局校验（尺寸为 8 的倍数、自然对齐、不重叠、位域在整型内、枚举存在、scale 只用于整型）。
- `tools/contracts/gen.py` → `python/awr/contracts/`（14 个模块）：`enums`（IntEnum、IntFlag、子模式表、TIME 状态字节助手）、`layouts`（numpy dtype、偏移、scale、none 哨兵、位域、`pack_fs`、`pack_ctrl`、`lite_from_full`、`SIZES`）、`frame`（struct、TIME 编解码、BATCH 帧头与记录迭代、`write_awrrt`、`read_awrrt`）、`reasons`、`commands`（服务匹配、准入列与符号查表）、`topics`、`units`、`bus_keys`（key 常量与构造函数）、`rng_streams`、`safety_codes`、`presets`（presets.json 原始字节、sha256、字段下标常量）、`schema_types`（TypedDict）。
- `tools/contracts/gen.mjs` → `packages/contracts/gen/ts/`（12 个模块）：DataView 访问器（读写、零分配 out 参数、i64 按 lo + hi·2³² 精确到 2⁵³）、`decodeSwarmLite32Into`（缓存视图的 SoA 解码）、`frame.ts`（帧头、`nextRecord`、`writeClientData`、`readAwrrt`）、`time.ts`、枚举、原因码、命令与准入、topics、单位、安全码、presets、`types.ts`（json-schema-to-typescript 生成全部 schema 的类型）。
- 两个生成器都支持 `--check`（有差异退出 1），Python 与 TS 计算出的 `LAYOUT_ID` 与 22 个 hash8 完全一致。

- Python：`python/awr/world/georef/{types,frames,time,leap_seconds,__init__}.py`。frames 覆盖 LLA、ECEF、ENU 互转（WGS84 与 CGCS2000，Zhu 1994 闭式解，极点处理）、ENU 与 NED、FLU 与 FRD、NED/FRD 四元数对合公式与批量 tap 版本、航向、ENU 与 three `(E, U, −N)`、相机 RDF 与 RUB、4×4 矩阵契约检查、PX4 等距方位投影与 `uavNN/local`（刚体与精确两种，带误差上界函数）、SIH float32 原点、UE 航线换算、Sim3（compose、inverse、gtsam 约定、插值）、精度报告。time 覆盖 GPST、UTC、TAI（PTP）换算、28 条闰秒表、GPS 周与周内秒、会话时基桩。

## 4. 与 PRD 的偏差及理由

| 编号 | 偏差 | 理由 |
|---|---|---|
| D-01 | `rt/reasons.json` 顶层为对象（`ranges`、`detail_only`、`warnings`、`reasons[]`、`ws_close_codes[]`），17 §10.5 写作数组 | 码段、仅 detail 码、警告码与 WS 关闭码需要同一真源；生成器与 i18n 读取 `.reasons` |
| D-02 | `rt/units.json` 为 `{suffixes, denied_suffixes, denied_names, unit_like_tokens, exceptions}` | UNIT-01 需要禁用后缀、禁用名与例外表（AWR-03 §5.4） |
| D-03 | commands.json 的准入为按列名的对象，并增加 `admission_columns`、`admission_symbols`、`admission_conditions` 与每行 `admission_cond` | AWR-12 §5.2 的脚注条件（READY_TO_ARM、AGL ≥ 2 m 等）必须机器可读；测试直接对照文档表 |
| D-04 | layouts.json 增加 `kind`、`const`、`enum` 属性，并收录 17 个头部布局 | 所有二进制头（BATCH、TIME、AWRT、AWRV、StateRing 等）由同一文件生成并纳入 `layout_id` |
| D-05 | 类别码表去掉 `$schema` 相对路径；g03 世界实例按 16 v1.0 改写后放入 `fixtures/world/` | 原相对路径迁移后失效；v1.0 新增必填字段 |
| D-06 | TS 契约测试放在 `apps/web/tests/contracts/`（17 §10.6 写 `packages/contracts/tests/layouts.test.ts`），并由 `make test-contracts` 调用 | 按任务书与 AWR-03 §4.3 的测试目录归属；Vitest 配置只覆盖 apps/web |
| D-07 | 17 §10.6 第 2 项的 `git diff --exit-code` 改为各生成器 `--check` | 本期不使用 git；`--check` 与之等价且不依赖仓库状态 |
| D-08 | `LAYOUT_ID` 在实现期间由 0x80A20EB8 变为 0x3D5E08D0（EnvSample32.rho 的单位写法改为与 units.json 一致的 `kg/m^3`） | 单位写法统一；数值只从生成物读取，无硬编码 |
| D-09 | `tools/ci/bom.json` 不存在，check-deps 以降级模式运行；锁文件中经 cmdk、react-scan 引入的 Radix 与 eslint 传递依赖只作提示 | BOM 不属本工作包；X10、X37 针对直接使用，传递依赖无法移除 |
| D-10 | `awr.LidarScan8.v1`（V0.2）未进入 layouts.json | 非 D1；topics.json 中该 topic 标为非 D1 |
| D-11 | env golden 未含 `turb_small.awrv` | 需要 M07 的 vk_box 与 AWRV 编解码 |
| D-12 | 闰秒表有效期常量按 IERS Bulletin C 71 取 2026-12-28 | 本机无法核对 Bulletin C 72，已请 M02 确认 |
| D-13 | check-brand 在 `brand.lock.json` 未交付时只提示（`--strict` 时失败）；BRAND-04 由 M15 的 Playwright 用例承担 | 该文件属 M15；静态 lint 无法测计算样式 |
| D-14 | MOT-03 以源码中声明的无限循环数量近似"同屏常驻循环"（组件库目录外 > 2 即违规） | 同屏数量只能在运行时由 Playwright 统计 |
