## 0. 评审结论

1. **维持结论 C（C0）**，不重开裁决。G5 补测通过，只是把首轮的"未测"项改为"通过"；决定性指标 G4 仍未达标（无观感增益），G1、G2 在 v1.3 门限下不通过，结论 A 的前提不成立。按 §6.4.2 与 ADR-187 后果条，补测结果不改变结论 C 时不重开裁决。用户已在 2026-10-12（R-D3-52）与 2026-10-17（R-D3-58）两次确认结论 C0，本次评审没有发现推翻这一确认的新证据。
2. **D3-AC-64 判定为通过**（应交付，P0b 两项应交付中的一项）。逐条对照见 §6：G1 至 G8 均有测量或引用，备忘与 ADR 已形成，G5 补测完成且 AP 门限通过；G4 按 v1.4 修订条款移至 D3-AC-68，"有真实验证集时差距不扩大"因无真实航拍验证集登记为未测。本判定以本记录经用户确认为前提（ADR-194 决策 (8)）。
3. **G5 幻觉审计门限冻结**：G-3DGS v2 在 G5 中新增的幻觉审计门限标为"暂定，首次复测后冻结"。G64 是首次复测。本记录起草 ADR-206，把审计冻结为"同噪声键成对比较下的两项计数判据，加抽样目视复核"（推荐，待确认，C-15）。b4 在暂定门限（每帧新增 0.098 ≤ 0.1）与冻结门限（净增 −0.12 ≤ 0.1；新增 0.098 ≤ 0.157）下都通过。因此 D3-AC-64 的判定不依赖冻结方案是否获得确认。
4. **`gs_eval` 产品化不计入 D3-AC-64**。M25-FR-193、200 与 M25-AC-051、055 的唯一使用方是 P3 入口门。推荐把它们移入 WP-D3-42（D3.x 顺延，封板计划任务 GS02），不作为封板门（推荐，待确认，§5.2）。
5. **C0 实施核对**发现一项与本条无关的缺口：`appearance = 3dgs` 在 P3 之前返回 643（M27 V07、AWR-17 BN-40 修订条）尚未实现。原因是 BN-40 `POST /runs` 本身尚未实现。登记为遗留，由 BN-40 的实现任务处理（§5.1）。

### 3.2 方法复核

| 复核项 | 结论 |
|---|---|
| 对照设计 | 同一视角的各变体共用噪声键与曝光误差相位，变体之间只有背景外观不同；演员像素、几何、遮挡与标注恒取网格（C3 合成），符合 §6.4"不变量"条 |
| 灵敏度 | b1（已知有害）下降约 7 个百分点，区间下界 4.3 个百分点，说明流程能检出有害外观层；b4"不下降"不是灵敏度不足造成的 |
| 坐标对齐 | r11 的 `T_world_source` 与产品世界只差高程平移 1.094441 m；工具校验旋转与尺度一致后才平移。对齐后掩膜内 PSNR（34.6 / 33.2 / 21.8 dB）与 r11 §4.3（33.0 / 32.1 / 21.6 dB）一致 |
| 检测器与权重 | 使用定稿 `ref_det_v1` 1.0.0，sha256 校验通过；AP 口径为 COCO 101 点、IoU 0.5 与 0.3 两档，与检测器训练评估口径一致 |
| 视角数量 | 每个 AGL 档 150 个，低于 §6.4 协议的 ≥ 300 个，与首轮"单街区"偏差同属已登记的协议偏差；P3 入口门按协议执行（§6.4.8）。区间上界距 2 个百分点门限的余量在 1.7 个百分点以上，视角数加倍不会改变判定 |
| 幻觉审计 | 逐帧"新增"计数在 0.1 量级上由工作阈值附近的抖动主导：不可能生成新目标的产物 A 为 0.107，换噪声种子达 0.249；b4 的 44 个新增检测中有 26 个在网格帧同一位置有 0.1–0.3 分的检测。G64 抽样目视复核了 8 处（r11 插图），因此需要先冻结审计口径，见 §7 |
| 新增检测全量目视复核（H06） | 本次评审对 b4 背景帧的全部 44 个新增检测逐一复核。方法：以 `g5_eval.py` 的判定规则（工作阈值 0.3、同类 IoU < 0.3）重新列出新增检测，个数与 `g5.json` 一致；每处取网格与 b4 的 C3 合成图（未加效果链）并排裁切，并标出检测框。结果：44 处全部为人员类，分数 0.30–0.51（中位 0.33）；28 处在网格帧同一位置（同类 IoU ≥ 0.3）有低于工作阈值的同类检测，其中 26 处分数为 0.1–0.3（与 r11 §4.6 的 26 处一致），2 处低于 0.1；其余 16 处网格帧同一位置无检测。框内内容在网格与 b4 中都存在，均为既有纹理：垃圾桶与色块、红色篷布、屋脊与檐口、树团边缘、阴影与路面斑点。b4 只是把这些纹理轻度模糊，未发现生成的人员或车辆 |
| 航拍域检测器 | §6.4.4 要求以"VisDrone 等数据训练"的航拍域检测器做幻觉审计。G64 以 `ref_det_v1` 充当：它是无人机视角检测器，但只在 crop 网格渲染上训练，没有用真实航拍数据训练，对生成式纹理的泛化未知。b1 的生成式幻觉（芭蕉叶、拱门）不属于人员或车辆类别，检测器不会报告。评审意见：P0b 以 `ref_det_v1` 完成本条可以接受；P3 入口门须补充以公开航拍数据训练的检测器，只在研究镜像中训练（§6.4.8 参照集规则第 3 条），纳入 ADR-206 决策 (4) |
| 环境 | dmax GPU 2（同卡有他人服务驻留、利用率 0%）。G5 是检测质量指标，不是性能指标，ADR-194 决策 (7) 的独占卡要求不适用 |

### 3.3 解读复核

r11 §4.6 把 mAP 略升解释为：3DGS 背景比网格模糊，烘焙纹理中的人形、车形高频内容被削弱，有演员帧的误检由每帧 0.90 降到 0.73–0.75，同时漏检没有增加。评审同意这一解读，并同意其限定："这不代表 3DGS 背景更好，只说明在 C3 合成下背景外观替换不损害演员的可检测性"。对外表述与数据集说明不得把该结果写成 3DGS 外观"提升检测性能"（§6.4.6 风险 39 的缓解条款）。

## 4. 裁决复核：是否重开

| 判断项 | 依据 | 结论 |
|---|---|---|
| 结论 A 的前提 | §6.4 决策条：全部必须项通过且 G4 达标 | 不成立：G4 不通过；G1、G2 在 v1.3 门限下不通过；G3 不可判定 |

评审结论：维持结论 C0，不重开裁决，不新增推翻或修订 ADR-188 的 ADR。

## 7. ADR 草案

### ADR-206 G-3DGS v2 的 G5 幻觉目标审计门限冻结（修订 §6.4.4 G5 行"暂定，首次复测后冻结"；细化 ADR-187 决策 (3)；落实 ADR-194 决策 (3)）
- **状态**：先行生效，待封板前用户确认（2026-10-19 由 Opus 依据 G64 补测结果起草，AWR-05 §23.5 C-15）。
- **背景**：ADR-187 决策 (3) 在 G5 中增加航拍域检测器的幻觉目标审计，§6.4.4 的门限为"相对网格渲染，每帧新增人与车辆检测数 ≤ 0.1（暂定，首次复测后冻结）"。ADR-194 决策 (3) 规定标"暂定"的阈值须先以 ADR 冻结再判定。2026-10-19 的首次复测（G64，r11 §4.6）显示，逐帧"新增"计数在 0.1 量级上由工作阈值附近的检测抖动主导：只由网格渲染训练、不可能生成新目标的产物 A 为 0.107，同一网格画面只换传感器噪声种子即达 0.249，最不受约束的 b1 反而只有 0.089。绝对门限 0.1 因此既会误判产物 A，也不能区分抖动与真实幻觉。
- **决策**：(1) 审计以同噪声键成对比较执行：同一视角的网格与各变体共用效果链噪声键与曝光误差相位，变体之间只有背景外观不同；只统计无演员的背景帧；检测类别为人员与车辆；工作阈值 0.3；"新增"指与同一视角网格帧任一同类检测 IoU < 0.3 的检测。(2) 判据（对 `generative` 来源判定，对 `mesh_distilled` 与 `aerial` 只报告）：① 每帧检测数净增（变体 − 网格）≤ 0.1；② 每帧新增检测数（相对网格）≤ 同瓦片产物 A 的值 + 0.05，产物 A 以同一视角集、同一噪声键测得；③ 抽样目视复核新增检测：生成网格与变体并排图，抽查不少于 20 处（不足 20 处时全查），复核结论写入报告，发现生成的人员或车辆即判不通过。三项同时满足为通过。(3) 报告另列：相对产物 A 的新增数，以及以 `--reseed` 测得的网格噪声本底；两者只作解读参考，不参与判定。(4) 检测器：P0b 与 D3 封板范围内以定稿 `ref_det_v1`（版本与权重 sha256 写入报告）充当航拍域检测器；P3 入口门（WP-D3-42）另加以公开航拍数据（VisDrone 等）训练的检测器，只在研究镜像中训练（§6.4.8 参照集规则第 3 条），两个检测器分别按 (2) 判定，任一不通过即审计不通过。(5) 不变：G5 的 AP 门限（IoU 0.5 与 0.3 两档 mAP 下降均 ≤ 2 个百分点，点估计判定，同时报告以视角为单位的成对自助法 95% 区间）；G2 的绝对门限"低空轨迹相邻帧重投影 MAE ≤ 1.0 级"仍为暂定，在 P3 入口门复测后以 ADR 冻结（§6.4.7 第 4 条）。(6) 参照实现为 `tools/bench/d3/g5_eval.py` 的 summarize 阶段，`gs_eval` 产品化时按本 ADR 实现（M25-FR-200）。
- **备选**：(a) 保留绝对门限"每帧新增 ≤ 0.1"（否决：产物 A 为 0.107，会把不可能产生幻觉的外观判为不通过；换噪声种子即达 0.249，门限落在抖动范围内）；(b) 只用每帧检测数净增（否决：生成目标替换被模糊掉的既有检测时，净增可以为零甚至为负）；(c) 以噪声本底为参照（否决：本底反映传感器噪声，不反映重渲染引起的抖动，且每次复测须多跑一遍全量推理）；(d) 只做目视复核（否决：不可复现，不能自动化回归）。
- **后果**：§6.4.4 G5 行的"冻结建议"改为冻结门限并引用本 ADR；r11 §4.6 第 5 条与 §7.5 G5 行改为"已冻结（ADR-206）"；M25-FR-200 的幻觉审计按本 ADR 实现；按本 ADR，b4 的两项计数为 −0.12 与 0.098 ≤ 0.157；评审对全部 44 个新增检测做了目视复核（本记录 §3.2），未见生成目标；三项同时满足，通过；D3-AC-64 在暂定门限下同样通过，判定不依赖本 ADR 是否获确认。用户否决时回退为暂定门限 0.1，b4 仍通过，产物 A 的审计结果只报告、不判定（现行 `g5_eval.py` 即如此）。
- **依据**：ADR-187 决策 (3)；ADR-194 决策 (3)、(8)；AWR-05 §6.4.4、§6.4.7；r11 §4.6、§7.5；G64 补测结果（`g5.json`，2026-10-19T03:02:11Z）。
