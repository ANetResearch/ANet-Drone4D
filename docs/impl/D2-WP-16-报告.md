## 2. 设计要点

### 2.1 前缀键

规格给出的近似做法（"IPv6 取前 4 组或 `::` 之前的组"）在对拍中暴露两个问题：`::` 落在前 4 组之内且其后的组也在前 4 组之内时
（如 `1b11::fd74:f756:1a5f:208f:3b07` 的 /64 是 `1b11:0:0:fd74`），近似键把不同的 /64 合并成一个键。实现改为按 `::` 之前的组数 p
与之后的组数 k 补出前 4 组：规范压缩文本只压缩连续 ≥ 2 组的 0，因此只有 p = 0、k ∈ {5, 6} 与 p = 1、k = 5 三种情形需要单独的规则，
共 9 条（含 IPv4 映射）。每个 /64 恰好对应一个键（前 4 组的十六进制文本），同一 /64 的不同压缩形式也得到同一个键；200 个地址的
用例与 10 万个随机地址的核对均为 0 例不一致。

### 2.2 静态世界与对拍口径

nginx 无法复现 show-api 的 ETag 取值与 `?v=` 不一致时的 409，按 `d2-WP-03-to-M00.md` 第 4 条只比较语义。容器内实测登记三处差异：
①ETag 取值；②206 上的 `Accept-Ranges`（nginx 只在 200 上声明；前端 `fetchJob.ts` 只认 `Content-Range`）；③416 的 Cache-Control、正文与
安全头重复（nginx 1.24 对 416 再走一遍头过滤器，`add_header always` 的值出现两次，同源请求下无影响）。另外 `?v=` 与当前
contentVersion 不一致时 nginx 照常 200 immutable：世界包只随发布更新，world.json 恒为 no-cache，访客下一次载入即拿到新 contentVersion。
反向代理的响应由 api 自带安全头，nginx 只在直出的 location 添加，避免重复的 COOP 被浏览器当作无效值；任何带 `add_header` 的
location 都重复写 HSTS（`add_header` 不继承）。

### 2.3 cgroup 包装与池的衔接

包装脚本使用与 `awr.runtime.cgroup` 相同的环境变量（`AWR_CGROUP_FS`、`AWR_CGROUP_ROOT`、`AWR_CGROUP_SIMULATE`），因此测试能用普通目录
模拟 cgroupfs，并直接用池的 `PoolSettings` 读同一个模拟单元，核对 Q、委派判定与 `sandbox/cpu.max` 的公式值。先建组、把单元根的全部进程
移入 `core/`，再启用控制器（cgroup v2 的"无内部进程"规则）；控制器逐个启用，缺一不影响另一个；任何一步失败都只记入告警，最后总是
exec supervisor。池的内存准入额度原本是配置常量（1100 MB），配额降为 1.6G 时需要手工改为 950：包装脚本按实际写入的
`sandbox/memory.high` 导出 `AWR_SANDBOX_MEM_MB`（env 中已设置时不覆盖），使 drop-in 改配额后 N_max 与准入自动跟随。

### 2.4 世界包

世界包按内容版本与 world.json 摘要命名，派生缓存包按内容版本与派生键命名，同名即复用（开发机与服务器两侧都跳过），rsync 只传
变化的包；索引与 WORLDS.sha256 互相校验，安装前逐包 deep 校验。校验放在切换发布之前并使用新发布的代码：派生键由
`DERIVE_VERSION`、`GeoParams`、contentVersion 与坐标摘要决定，旧发布的代码判断不了新包。服务器上不能重建六城（没有原始数据），
因此 install.sh 只对 synthcity 保留"缺失即生成"的 D1 路径；其余世界缺失或不可用时停止安装（来自本次世界包）或只告警（未部署）。

### 2.5 构建信息与启动屏的过渡

轨道实现为 `.boot-progress > i.boot-track > i[data-seg]`：`.boot-track` 是第一个子元素，D2 的单条写入器（`entry.tsx`、`app/boot/progress.ts`
写 `--boot-p`，`styles/boot.css` 缩放 `.boot-progress > i`）在 WP-12c 改为分段写入之前仍然得到与 D2 相同的视觉；关键 CSS 以更高的
选择器优先级保持轨道为 flex，脚本执行前即显示五段空轨道与版本号。`__AWR_BUILD__` 与显示串的格式由 `vite.config.ts` 导出的纯函数
定义，便于 M15 与 M16 复用同一口径。
