## 3. 偏差与原因

1. **任务暂停的实现层次**：PRD 的 M04"STOP_MOTION 悬停"在轨迹执行下由跟踪器时钟斜坡实现（FR-007 原文如此），但 M08 原生 pause/resume
   对提供者接管的调用会被原生导航覆盖，因此任务级暂停完全在跟踪器内完成（`pause_slot/resume_slot`），调用保持在途，截止时间经
   M08 表直接延长（已请求 M08 提供公开接口）。
2. **样条拟合**：控制点取 Schoenberg 采样（与 PRD §6.5.6 一致）。随机"对抗"折线（转角接近 180°）偏差可达 0.57 m，AC-004 类折线
   （转角 ≤ 120°）满足 ≤ 0.5 m；曾尝试插值型控制点，偏差反而增大，已回退。
3. **测试文件位置**：AC 表中的 `tests/sim/test_scenario_loader.py` 属 M08 路径，改放 `tests/mission/test_scenario_loader.py`；
   `test_orbit.py` → `test_orbit_goto.py`；`test_pause_yield.py` → `test_fsm.py` + `test_yield.py`；`test_binding.py` → `test_transit.py`；
   `test_search_corridor.py` → `test_generators.py`；`test_formation.py` → `test_formation_run.py`（均在 M10 自有目录）。
4. **mk/m10.mk**：PRD 写 `TEST_TARGETS += test-mission；BENCH_TARGETS += bench-plan`。`mk/common.mk` 规定 make test 已全量运行
   pytest 与 Vitest、模块不得重复登记，且没有 `BENCH_TARGETS` 扩展点，因此只提供便捷目标 `test-mission`、`bench-plan`，并把 numba 预热
   登记到 `RUN_PRE_TARGETS`。
5. **4 m 规划栅格阻塞禁飞区**：§6.5.2 未写区域处理；实现把 nofly 与 border 外的格置 +inf（外扩 1 格），起终点格不阻塞，最终仍由
   `path_valid`（含 zones）校验。对角移动在两侧格高于 max(h_n, h_m) + 1 m 时禁止切角，保证超覆盖剪枝"不引入新爬升"的性质；
   两段坡长之和超过段长时整段按较高者飞行（坡度可陡于 γ，但仍按构造安全）。
6. **生成器抬升余量**：沿段 Height_map 最大值之上再加 1.0 m（= 圆角 e_max），否则上海样本在台阶处圆角切角后有 0.09 m 低于
   Height_map（仍高于 DSM 约 10 m）。
7. **编队集结拆成两次调用**：LIFTING（每机 TOPP-lite 竖直段）与 ASSEMBLING（CAPT）之间做一次全员同步。原因：M08 对 follow_path 的
   停滞判据为"5 s 内位移 < 0.2 m"，长时长 smoothstep 与竖直段起步过慢会被判 203。CAPT 的目标最小间距取
   min(min_sep_m, 0.95·起点构型间距, 0.95·终点构型间距)（起终构型本身更近时 min_sep 不可达）。成员丢失只实现 keep_slot（compact
   按 keep_slot 执行并在事件中报告请求的策略）；RESHAPING（变形）未实现；巡航中被挂起的成员续飞时按单机轨迹入场，不再回到群组时钟。
8. **任务内 4D 消解的时间基准**：对各机首个 B-spline 作业项做检查（不含入场转场）；有延迟或错层时首个作业项先全员同步（各机到达
   起点后等待，上限 300 s【仿真】），再按延迟起步；轨迹结束后按"停在终点"保守处理。编队任务不做 4D 检查（CAPT 与群组时钟保证）。
9. **覆盖快照"仅在有订阅时发布"**：sim-core 不掌握订阅集，改为 RUNNING 且栅格有新戳记时 ≤ 1 Hz 写文件并发 `coverage.changed`，
   由网关只推给订阅者（已请求 M11）。R24 `coverage_grid` 描述的是快照几何（res_m 已乘抽取步长 k）。
10. **动作 yaw 与 wait_sync**：航向由生成器写入作业项航向规格（跟踪器航向模式），`yaw` 动作不另行执行；`wait_sync` 未实现，
    barrier 由 `sync_policy = barrier` 提供；`timed` 同步策略未实现（ext）。
11. **S1 成功谓词**：M10 测试台未装配 M07/M09，M08/M09 的度量（`min_separation_m`、`guard_events`、`pos_err_max_m`、`landed_all`、
    `battery_soc_min`、`energy_rtl_count`、`landed_home_err_m`）缺失判假，`scenario.result` 为 FAILED；M10 自有谓词全部成立。
    `elapsed_s`、`landed_all`、`landed_home_err_m` 属 M08，尚未登记（已请求）。
12. **规划器 D1 的 A* 城市样本**：AC-017 要求六城 × 40 组与时延 p95，并行阶段只跑功能：合成世界的 4 个用例 + 深圳 6 组随机起终点
    的 `path_valid` 与按构造安全检查；时延断言属 perf。
13. **REST 任务控制**：保留 `POST /api/missions/{mid}/{op}`（经查询 `mission/control`）作为 WS 服务的 REST 镜像，与新登记的
    Command 处理者等价。
