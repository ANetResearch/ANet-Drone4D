## 3. 与 PRD 的偏差及理由

| 编号 | 偏差 | 理由与影响 |
|---|---|---|
| D-01 | EnvironmentService 由插件在首个 env stage 或心跳慢任务时惰性构造并挂到 `ctx.env`（世界目录、world_seed 从 `AWR_WORLD`、`AWR_WORLDS_DIR`、`AWR_WORLD_SEED` 读取） | M08 组合根当前不构造 EnvironmentService，StageCtx 也没有这三项；已请求 M08 在启动期显式构造（资产生成移入启动） |
| D-02 | 点云光照的云阴影是轨道焦点处的标量（CPU 用同一天气图掩码求值），不是逐顶点；网格材质未接环境光照 | M05 只提供 `setLighting(sunEnu, cloudShadow)`，M06 尚无 SceneShadingProvider；逐顶点实现已在 `EnvShading.lambert()` 中（编译并对拍通过），待 M06/M05 接入 |
| D-03 | 2D 云用远平面上的透明全屏四边形过渡绘制（深度测试只覆盖清屏深度处），Tier S 多 1 次 draw | M06 的 SkyQuad 与 P2 背景未调用 `sky()`；接入后删除该四边形。雨换档交叉淡化的 500 ms 内雨占 2 次 draw |
| D-04 | 选中机本机读数由客户端同式求值（`selected.source = 'local'`） | EnvSample32 在帧的 raw 区，模块无法取得（已请求 M06 暴露）；数值与服务端同式，差在湍流项（Low 不加载湍流盒时本机读数不含湍流） |
| D-05 | 雪与沙尘在所有档用 GLPoints（Tier A 未改扁平四边形） | Tier A 不在 D1 验收档位；点尺寸在 Tier A 恒 1 px，视觉略弱 |
| D-06 | `env/set` 只改用户轴（风向、垂直风、ISA、湿度）且当前稳态在某预设时保留 `to_preset` | 用户轴不属于预设快照，改风向不应让面板的预设选中态消失；其他字段修改后 `to_preset = null`（PRD 原文） |
| D-07 | `env_seed = hash32(world_seed, "env")` 定义为 sha256("env|world_seed=<s>") 前 4 字节小端 | PRD 与 17 未给出 hash32 的具体定义，与 field_version 同式 |
| D-08 | 天气图云漂移偏移取 `−(f(h_mid)·D) mod scale`（负号） | 按 `m(xy + offset)` 取样时，只有减去漂移量云才顺风移动；与云阴影同一偏移，对齐不受影响 |
