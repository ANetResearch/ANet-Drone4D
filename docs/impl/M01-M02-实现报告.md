## 4. 与 PRD 的偏差及理由

1. **M03 `IngestFromArrays` 未交付，TILING/PACKAGING 使用过渡实现 `pipeline/m03_bridge.py`**：只调用 M03 库函数，派生世界沿用源世界锚点与原点。为通过 M03 现行校验器有两处过渡写法：(a) V-C-06 要求 `source.upAxis` 映射到 world +Z，引擎规范系做不到，暂把声明的源帧取为"按 `T_world_map.q` 旋转后的引擎系"（`T_world_source = [[s·I, t],[0,1]]`，`evidence` 注明；`registration.T_world_map` 与 `alignment.json` 保持精确）；(b) V-W-11 不把 `session.json` 视为 sidecar，会话图层 href 暂用目录 `reconstruction/<session_id>/`（M01 §6.8 为 `.../session.json`）。M03 交付 `ArraysAdapter` 与规则修订后自动或按请求改回（请求 M01-to-M03 第 1–3 条）。
2. **Recon IR schema 暂存于 M01 路径**（`ir/schemas/`），加载器与 `rest/recon.py` 在 M00 合入后自动改用 `packages/contracts/recon/`（请求 M01-M02-to-M00 第 1 条）。ReconEngine、ReconStage 与随机流 11–16 尚未进入生成物，代码暂用 `types.py` 常量。
3. **V16 只检查各文件顶层键**：M01 §6.3.3 规定 `input` 与任务参数 `source` 同构（含源世界的 `world_id`），递归检查会误判；上下文字段只会出现在顶层。**V10 加强**为"method = none 当且仅当 scale_status = relative，且此时 status 为 rejected 或 skipped"，否则变异 ⑥（gnss-sim3 且 relative、status accepted）按字面规则拦不下。
4. **Mock GNSS 直接调用 M02 `MockGnss`**（流 9，跳点幅度区间 15–40 m），不再单设 M01 `mock_gnss.py`（M01 §14 第 19 条的目标状态）。PREPARING 未写草稿 `session.json`，`session.json` 只在 GEOREFERENCING 末尾写一次（保证"`session.json` 完整即会话完整"）。
5. **参数 schema 增加两个可选字段**：`params.mock.gravity_noise_deg`（§6.4.1 参数表有、§6.9 未列）与 `params.fuse.min_points`（§6.5 的"最少融合点数"）。
6. **Sim3 精度阈值按统计口径实现**：M02-AC-016 与 M01-AC-017 的阈值来自 r02 单次运行。60 个 SPP 定位（σ 2/2/3 m）做 7 参数拟合时 ATE 期望约 0.8–0.9 m、单次可达 1.5 m；50 帧 400 m 直线在 SPP 下尺度误差的标准差约 0.25%、旋转约 0.25°。测试改为多种子均值（环绕 20 种子：ATE 均值 ≤ 1.0 m、尺度均值 ≤ 0.5%；直线 8 种子：旋转均值 ≤ 0.5°、尺度均值 ≤ 0.5%），RTK 档仍逐例满足 ≤ 0.01%/≤ 0.05° 与 ≤ 0.1%。M01-AC-017 GNSS 档"尺度误差 ≤ 0.1%"在该噪声下不可逐例达到，建议 MS6 修订为均值口径。"RMSE ≤ 0.02 m / 1.0 m"按 r02 的定义解释为与真值的相机中心误差（ATE），`report.rmse_m` 是对观测的残差。
7. **LO-RANSAC 的退化样本处理**：M01 §6.6.2 伪代码丢弃 `sv₂/sv₁ < 1e-3` 的最小样本；直线航带上所有样本都共线，按字面会无解。实现为：整条轨迹非共线时才丢弃近共线样本，否则保留（点到点内点判定与绕航线轴的旋转无关，旋转由随后的重力增强确定，r02 §3.5）。
8. **可复现口径**：`geometry/pointcloud/source/source.json` 含 `world_id` 与 `coordinate_sha256`（M03 设计），不同目标世界必然不同；M01-AC-011 按点流（`xyz.f32`、`normal.u16`、`class.u8`）逐字节比较（请求 M01-to-M03 第 7 条）。
9. **功能测试规模缩小**（CPU 紧张）：链路 60 帧、精度 300 帧 × 2 种子、取消每阶段 1 次（PRD 为随机 3 次）、性能锁持有 3 s（PRD 为 10 s）；验收尺寸为 `slow` 用例（600 帧链路；600 帧 × 3 种子精度，其中 source_keep 取 0.10 以控制时长）。
10. **进度事件严格节流**：阶段结束的进度也受 250 ms 限制（不强制发送），暂停状态在 250 ms 内经 `flush_progress` 送出；终态 `job.state` 携带 `progress_pct = 100`。
11. **R38 路由放在 `rest/recon.py`**：M01 §2.1 写的是 M03 的 `rest/jobs.py`，本工作包按 AWR-03 §4.3 路径表（`recon.py` 归 M01）与任务书实现；R39–R42、R64 仍归 M03。
12. **未实现**：DA3-SMALL CPU 冒烟（V0.2，P2）；`retain.raw_points` 的 `points/` 写出（缺省关闭，V18 已支持校验）；G5 分块门禁与分块 Sim3（V0.5）；时间偏移搜索只在 M02 库中实现，M01 按 D1 传 0；C2C 用 20 万点样本（不是全部融合点）。
