## 0. 摘要

1. **载入进度条**（M15-FR-201，UX-FR-101、102）：模型 `lib/bootProgress.ts` 是纯函数，五段加权（bundle 0.15、world 0.10、points 0.40、warming 0.30、reveal 0.05；warming 内部按着色器 0.6、界面 0.4 分配）。每段只增不减，总值也只增不减；减少动效时按段边界跳变。写入器 `app/boot/progress.ts` 写入频率 ≤ 10 Hz，增量不足半像素时不写，用 `--boot-p` 驱动 `scaleX`，揭开前同步置 1，出错时冻结。进度来源有三处：BootController 新增的 `onGate` 门回调、`stores/world` 的阶段，以及 uiWarm 的子阶段。演示构建的入口 `app/demo/entry.tsx` 内联了一个 bundle 段观察器（Resource Timing 加 modulepreload），不 import 共享模块，因此落地页仍然只加载 4 个脚本。换底图和静态浏览时，载入层 `ui/boot/LoadingLayer.tsx` 去掉 bundle 段后重新归一。
2. **角色、界面与路由**（FR-202、203、205，UX-FR-103、104、105）：`app/shell/surface.ts` 根据路由、会话和演示开关解出五种界面：local、shared、static、sandbox、sandbox-gone。`useSessionRole()` 和 `useSandboxOperator()` 决定写操作是否可用。新增路由 `/sandbox/api`（先登记）与 `/sandbox/:sid`（正则 `^sb-[a-z2-7]{10}$`）；`lib/demo.ts` 列出七个世界。角色徽标、只读文案、页面标题、"沙盒"菜单和帮助菜单都已按 §20.2 改写。
3. **开启沙盒与排队**（FR-204、207、208，UX-FR-106 至 111）：落地页第二个主按钮打开 `SandboxLaunchSheet`（窗口小于 1280 × 720 时禁用，不发请求）。Sheet 里有世界可用性、T1–T6 模板（缺省 T5）、时段、快照恢复。工作量证明在 Worker 中求解，超过 300 ms 才显示"正在验证"。各种响应的处理：201 进入沙盒；202 显示非模态排队卡片（长轮询，slot_ready 后倒计时 60 s，认领或离开）；508 列出可替代的世界；504 按 Retry-After 倒计时；200 但不带 token 时提示"在另一个标签页中"，可以选择接管。会话恢复使用 14 §20.4.7 规定的存储键。
4. **会话条**（FR-206，UX-FR-109、110）：会话条放在 AppHeader 中段，显示徽标、世界与模板、剩余寿命（每秒更新）、续期、倍速药丸（受限时给出原因）、实体计数和日历。操作有载入场景、换底图、重置、结束（AlertDialog 确认）、快照导出与导入。另外实现了即将结束的横条（导出一次快照到本地）、结束对话框（可"用快照新开"）和自动续期（多标签页只由一个标签页续期）。
5. **机队、识别物与机巢**（FR-211、212、213，UX-FR-112、115 至 125）：右栏用分段控件切换无人机、识别物、机巢三类实体。机型目录 Sheet 有卡片和 LfTable 参数表，克隆表单做前置校验并把 522 逐项映射到字段，可以添加无人机，载荷控件提供变焦、模式、调色板、照明器、云台。识别物部分有列表与筛选，放置、移动、路径、游走区域四种工具态；详情包括感知态、敏感体编辑表（配置体与有效体切换、建议半径与采纳）、高级属性九组和声源波形图（LfLine）。机巢部分有类型、库存、能量模式、充电通道（LfTickGauge）和兼容性提示。
6. **手动控制**（FR-215、216、217，UX-FR-132 至 135）：状态机为 IDLE → CONFIRMING → ACQUIRING → ACTIVE → STOPPING，按 30 Hz 发送 `publishSetpoint`，输入归零后补发零速度尾包。窗口失焦、页面隐藏或按 Esc 时停止并释放。`manual` 键位作用域优先级最高：屏蔽 F、Space、G、1–5，保留 Shift+R、Shift+L、Shift+X。虚拟双摇杆用指针捕获。速度档用 C 切换。接管期间倍速置灰。3 s 外推预测会进入禁入体时发出告警。软围栏开关由服务端执行，关闭时要求确认，被钳制时提示"已被软围栏限速"。
7. **提示与一处红**（FR-219，UX-FR-138、139）：`perception.capture` 以中性 Toast 提示（同一识别物 30 s 内只提示一次）；`target.discovered` 以 critical Toast 提示，带"确认"按钮（与告警中心的确认联动），作为 rank 5 的红色候选；`keepout_guard` 的钳制提示同一识别物 5 s 内只出现一次。还处理了 `sandbox.rate` 和 `session.switched`。事件面板增加四个 D2 筛选。
8. **世界、模板与引导**（FR-209、210，UX-FR-140、141、142）：World Hub 显示七个世界的沙盒可用性，提供"在此城市开沙盒"，六城卡片附授权说明和 ECCV 2022 BibTeX（Popover，可复制）。TemplatePicker 和 WorldSwitch 对话框已实现；换底图后跟随新世界（过渡做法是整页刷新，偏差 3）。新手引导 4 步，用非模态 Popover，可以跳过，只出现一次。
9. **OpenAPI 文档页**（FR-221，UX-FR-145）：数据读自 `GET /api/sandbox/v1/openapi.json`。左侧导航按所属文件分组（Collapsible），右侧操作卡片给出方法、路径、参数表，用 Tabs 切换 curl（token 用 `$AWR_SANDBOX_TOKEN` 占位）与 SDK 调用，并列出原因码；另有一张实时 topic 表。页面上不显示真实 token，只提供"复制 token"按钮。演示构建中这个页面有独立入口 `apiDocsEntry`，不经过 `main.tsx`。

## 2. 偏差

1. **过渡数据层**：沙盒会话用 `ui/sandbox/session.ts`；识别物、机巢、机型目录与克隆用 `ui/sandbox/domain.ts`（REST 加 TanStack Query，识别物实时状态由事件折叠得到）。M17 的 `stores/sandboxSession.ts`、M18 的 `stores/targets.ts`、M21 的 `stores/catalog.ts` 在 10-05 12:48 至 13:06 之间才交付，晚于本工作包的界面实现，本轮没有替换。替换清单见 §5，请求见 d2-WP-12-to-M17、M18、M21。
2. **setpoint 泵在主线程**：FR-215 要求经 `rt.worker` 发送。现在用主线程的 `setInterval` 按 30 Hz 调用 `rt.publishSetpoint`，不经过 React 渲染路径。需要 M11 提供 worker 内的节拍接口（d2-WP-12-to-M11 第 1 条）。
3. **沙盒换底图的过渡做法是整页刷新**：会话的 world 与 viewport 不一致时调用 `location.reload()`，会话从存储中恢复，界面不会丢失。原地换世界需要 M05 或 M06 提供接口（d2-WP-12-to-M05 第 3 条、M06 第 3 条）。
4. **index.html 与 vite.config 没有改**（M00 文件）：
   - 进度条的 CSS 写在 `styles/boot.css`，用不分层的选择器覆盖 index.html 内联样式中的 `width`。
   - bundle 段按块计步，没有按字节计（需要 M00 写启动清单）。
   - **`/sandbox/api` 在演示构建中仍然加载 `ui`、`r3f` 和 `three` 分块**，不满足 FR-221 的"不加载 three"。原因有两个：`ui` 分组把 `src/ui/**` 全部收进同一分块，而 zustand 落在 `r3f` 分块。我用一份临时配置验证过加 `state` 和 `apidocs` 两个分组的方案：加上后这个页面只加载 6 个脚本，没有 three、r3f、ui 和 engine，落地页不受影响。分组写法见 d2-WP-12-to-M00 第 1 条。
   - 落地页"开启我的沙盒"的 Sheet 懒加载时也会拉 `ui` 分块，但只在点击时请求，不违反 FR-121。
5. **速度档按 AWR-14 §20.18**：水平 2 / 5 / min(vmax, 10) m/s，垂直 1 / 2 / 3 m/s，偏航 0.4 / 0.8 / 1.2 rad/s。M15 PRD §15.4.3 的数值（1 / 3 / 8 m/s，偏航 45°/s）与此冲突，已转文档总编。
6. **存储键按 AWR-14 §20.4.7**（`awr.sandbox.session.v1` 等），与 M17 实现的 `awr.sandbox.v1` 不一致，已请 M17 改常量并转文档总编。
7. **GSD 与识别距离提示没有做**：克隆表单与载荷控件只显示能量派生量，因为 M19 计算器的 TS 入口还没定（d2-WP-12-to-M19）。
8. **敏感体显示切换的状态由面板导出**：`TargetDetailPanel.tsx` 导出 `sensDisplayStore`，在 M18 的 `setBodyView` 接入前使用。
9. **路径说明**：除 §14.2 的 glob 外，还写了 M15 模块自己的三处路径：`apps/web/tests/m15/**`（9 个测试文件，7 个新增）；`apps/web/perf/m15/sandbox-d2.spec.ts`（新增），以及 `perf/m15/fxweb2.spec.ts` 第 91 行的一处断言（"科研"改为"经数据集权利方授权"，因为 ADR-109 要求改关于页文案）；`tools/shadcn/icons/inventory.mjs`（新增 D2 图标键）。依据 AWR-03 §4.3：模块用例放在 `perf/m<nn>/`，`tools/shadcn/**` 归 M15。已请文档总编在 §14.2 补登记。
10. **接口文档页的分组控件**：FR-221 写的是"按 tag 分组（Tabs 与 Accordion）"。这里左侧导航按分组用 Collapsible（各组独立展开，缺省全部展开，组内列出操作链接），右侧显示所选操作的卡片，卡片里用 Tabs 切换 curl 与 Python SDK。没有用 Accordion，因为导航需要同时展开多个分组。用的都是 shadcn 组件。
11. **PRD 中的 `tests/m15/manual-control.spec.ts` 没有建立**：M15-AC-211 的 setpoint ≥ 25 Hz 与命令到可见 p95 需要真实后端，属于性能口径，按"并行阶段不跑基准"留给 M16 的 harness。功能部分由单元测试（作用域、泵、零尾、预测）和 Playwright 的接管确认流程覆盖。
