### 1.7 REST 探针（`python/awr/api/rest/world_query.py`，M04）

导出 `router`：`POST /api/world/{id}/query`。pydantic 按 op 校验（op 白名单、各 op 上限、坐标有限、方向为单位向量 ±1e-3）；路径世界必须为当前会话世界（409 `123`）；每 principal 令牌桶 10 次/s、突发 10（429 `111`，带 `Retry-After`）；转发 `svc/geo/{height,ray_hit}`（key 经 `awr.contracts.bus_keys.svc_geo`）：对 `awr.runtime.bus.ZenohBus` 以 `timeout=1.0, retries=2, retry_gap=0.3` 调用，由总线同体重试，`BusTimeout` 映射 503 `211`、其他 `BusError` 映射 503 `213`；对只有 `call(key, payload, *, timeout_s)` 的替身由路由自行重试 3 次；错误体为 problem+json；回复头 `AWR-API-Version: 1`、`Cache-Control: no-store`、`X-Request-Id`。路由不 import `awr.world.geometry`，校验 CPU < 1 ms（FR-026、AC-014、AC-015）。

## 5. 与 PRD 的偏差及理由

1. **DSM 钳到不低于格心 DTM**（FR-024）：原定义为"每格源点最大 z，空格取 DTM 双线性"。斜坡上的稀疏观测格最大 z 可能低于格心 DTM 双线性值，违反 V-G-05（DSM ≥ DTM − 0.01 m）；首版实现的校验曾报出 43 个这样的格。实现为 `max(格内最大 z, DTM 双线性)`，只影响极少数格；dsm_2m_n 仍记录真实观测数。
2. **HAG 栅格提前提供但默认关闭**（FR-025，P2 / V0.2）：`--hag` 开启时写出，默认构建不写，contentVersion 与规范表不变。
3. **测试归属**：16 §15 的 World 变异用例与 ANET_Q16 golden 放在 `tests/world/`（M03 路径），未写入 M00 的 `tests/contracts/`；Ajv 结构校验脚本放在 `tests/world/ajv_check_world.mjs`，作为 `tools/contracts/check-world.mjs` 的草稿交 M00 采纳（请求 `M03-to-M00.md`）。
4. **`awr data` 插件位置**：放在 M03 所有的 `python/awr/jobs/awr_cli.py`，因为 `python/awr/world/awr_cli.py` 不在 03 §4.3 路径所有权表中；M11 的 `_PLUGIN_MODULES` 已包含 `awr.jobs.awr_cli`，无需其他改动。`make fetch-data` 仍直接调用 `python -m awr.world.ingest.data_cli`，不依赖 `awr` CLI 可用。
5. **几何派生缓存格式**：每个缓存条目一份 manifest（数组名、dtype、shape、sha256）加原始数组，而不是每个数组一个 sidecar；原子落盘与每世界保留 3 条的语义不变。`open_world_query` 的 `cache_root` 缺省为 `<worlds>/.geo-cache`。
6. **REST 与总线的重试分工**：M11 的 `ZenohBus.call` 自带同体重试，路由对它只调用一次（`retries=2`），合计仍为 1 s × 3 次；对无内建重试的替身由路由重试。
7. **bus schema 与 op 名不一致**：`packages/contracts/bus/geo.schema.json`（M00-B 起草）的 `op` 枚举为 `height`、`ray_hit`、`raycast`、`los`、`lidar`，与 M04 §7.3 的 op 名（`height_dsm` 等）不同，回复缺 `detail` 字段。实现以 M04 PRD 为准，修订草案已写入 `M03-to-M00.md`。
8. **构建时间目标**：M03-NFR-001 的门禁（单城 ≤ 60 s）满足；目标"≤ 30 s（load ≤ 2）"上海串行 30.2 s（测量时 load 约 2–3，受并行 agent 影响）略超，其余城市满足。
9. **M04-AC-021 内存口径**：派生数组经 memmap 共享页缓存。旧金山打开后执行 20 万点高度与 AGL、2 万点净空、300 次 ray_hit 与粗校验，RSS 增量约 73 MiB（`test_memory` 门禁 ≤ 200 MB）；若把 sim-core 用到的全部派生数组逐页读一遍（`dsm_eff`、heightmap、`dsm_dil1` 与金字塔，不含 plan-pool 的 `inflated_1m`），增量为 206 MiB，略超 200 MB。实际查询不会触及全部页，报告保留该最坏值供 M08 评估。
10. **规则 G 首屏与 hierarchy 分页**：> 40,000 节点的分页按 PotreeConverter `createHierarchyChunks` 语义实现（步长 4、深度 4 节点为 PROXY）；六城节点数均 < 1,000，只在测试中覆盖分页路径。
11. **未实现或只有桩的功能**（均不在 D1-core）：job-worker 与 `rest/jobs.py`、`world.added` / `world.updated` 事件（FR-055 至 FR-057，MS6）；`IngestFromArrays`（FR-021，ext）；通用 PLY / LAS 导入（FR-020，V0.2）；精确去重（FR-022，V0.2）；CSF 语义（FR-019，P2）；`--twin-default`（FR-040，P2）；`make fetch-worlds`（FR-046，P2，发布位置未定时退出码 4）；3D Tiles、COPC、gz、USD 导出（FR-059、FR-060、FR-064，V0.5 起，退出码 3）；geo-worker 与 `svc/geo/{raycast,los,lidar}`（M04 V0.2）。
