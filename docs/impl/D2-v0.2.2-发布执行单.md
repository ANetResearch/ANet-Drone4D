fix(lint): REL-03 skips public model-id values on d2

check-release compared every value of ~/.config/awr/*.env against the
release set, so the public image model id named in LandingContent.ts,
LandingStory.tsx and the illustration manifest was reported as a
leaked credential and `make lint` failed on hosts with that env file.
Keys matching (^|_)(MODEL|MODELS|MODEL_ID)$ now name public

Backport of the REL-03 part of e155a21 (d3-dev). Refs: D3-AC-46, ADR-209
