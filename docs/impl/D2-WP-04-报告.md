## 0. 摘要

1. **池进程**（`python -m awr.sandbox.pool`）：单 asyncio 事件循环；broker（纯逻辑，注入时钟）管理会话表、排队票、地址前缀配额与令牌桶、工作量证明、续期、空闲与未认领回收、寿命告知、抢占、崩溃重启、切换底图与回滚、载入模板与恢复快照；治理器与降级阶梯是纯函数；拉起器以 setsid、日志文件、叶子组包装拉起沙盒 sim-core（`AWR_DETACHED=1`、`sandbox100`、`AWR_SIM_AUTOPLAY=0`），StateRing 心跳判就绪与挂死；状态 ≤ 1 Hz 合批落盘，重启后按 pid、starttime 与 `AWR_RUN` 核对并以 pidfd 接管；每会话一个总线会话（perf 订阅、以会话 principal 的 `K_entry` 签名调用 `play`、`speed`、`reset{sandbox_config}`、快照导出）；宿主 M10 的 PlanServer。
2. **池命名空间服务**：`sys/session/{create, get, list, keepalive, stop, rate, activity, queue, world, template, restore, snapshot, meta, worlds, templates, challenge, batch, ops}`，`K_pool` 验签（±5 s、签名覆盖 op），只接受 `svc:sandbox-api`（运维 `svc:sandbox-ctl` 只可调用 `ops、list、get、meta`）；1 Hz 摘要 `state/sandbox-pool/sessions`；事件 `evt/sandbox-pool/session`（`sandbox.state`、`sandbox.expiring`、`sandbox.rate`、`sandbox.slot_ready`）。与 WP-03 的 GatewayHub 契约逐项对齐，真实 sandbox-api 联调通过。
3. **REST**（`rest/sandbox.py`，挂在 sandbox-api）：SB-00 至 SB-19 共 20 个操作；会话对象按契约字段过滤；problem+json 与 `Retry-After`；公开目录类 ETag 与 304；时钟经网关 `rpc.handle_call`（`sim/speed` 先经池授予，受限为警告 501）；事件补拉取会话 Gateway 的 EventRing；排队长轮询（每票同时 ≤ 1 个，后到者使先到者返回）；每个操作带 `x-awr-reasons` 与 curl、SDK 两种 `x-codeSamples`。
4. **SDK**（`tools/sdk/awr_sandbox.py`，单文件 1.0.0，Python 3.9 语法）：自动工作量证明、429/503 按 `Retry-After` 退避、排队长轮询与 `slot_ready` 回调后认领、自动续期、`awr.rt.v1` 同步客户端（TIME 跟踪、BATCH 解码与自动 ack、内嵌 5 种 raw 布局表）、速度控制（`call velocity` + `advertise` + CLIENT_DATA，≤ 50 Hz）、`SandboxGone`；7 个示例与 README。
5. **前端**：`stores/sandboxSession.ts`（§7.9 全部阶段与动作、sessionStorage 与 localStorage 备份、BroadcastChannel 多标签页、单标签页续期租约、自动续期条件、`sandbox.expiring` 自动导出快照、1280 × 720 守卫、net 端点切换）；`net/sandbox/`（REST 客户端、in-repo SHA-256、工作量证明求解与 Worker）。
6. **配置**：`configs/sandbox/world_costs.json`（`awr.sandbox.world_costs.v1`，AWR-04 §4.4.2 初值，`measured: false`，待 M16 harness 替换）。

## 2. 设计要点

1. **broker 纯逻辑 + 副作用接口**。所有状态变化同步完成、先改内存再标脏；拉起、停止、切换、重置、时钟都经 `Effects` 交给池异步执行，完成后回调 broker。单测以记录替身和注入时钟覆盖 §6.6 的分支（18 个用例），集成测试以真实池事件循环覆盖进程与总线行为。
2. **测试替身贴近真实**：`FakeLauncher` 为每个会话拉起真实子进程（真实 pid、starttime、environ、setsid、pidfd、kill -9），同时在进程内起 tests/rt 的 FakeSim 承担 StateRing、时钟、perf 与快照；`SbxStack` 把真实池与真实 sandbox-api（GatewayHub、中间件、限流）接在一起，REST 与 SDK 用例走完整链路。
3. **时钟由池在 ACTIVE 时启动**：沙盒 sim-core 以 `AWR_SIM_AUTOPLAY=0` 拉起，未认领的会话不推进仿真；池以会话 principal（席位由 sandbox-api 固定给它）签名，因此 `play`、治理器降档与 `reset{sandbox_config}` 都通过 sim-core 的席位检查，无需新增内部 principal。
4. **切换底图不换 run 目录**：namespace 随世界变化即可被 hub 识别为切换（1012），环与 secret 位置不变；旧 tmpfs 在新进程拉起前删除，避免新进程误用旧环与 checkpoint。
5. **会话结束后仍在 `list` 中保留 600 s**（ENDED/FAILED + `end_reason`、`snapshot_available`），hub 据此回 410 506/510 并放行快照导出，而不是把会话当作"消失"。
