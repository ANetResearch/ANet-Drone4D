# 场景适配目标系统：相对 v0.2.0 的升级说明

本分支将原生“识别物”扩展为可选的精细外观、场景约束、持续身份和自主生活行为系统。当前完整验收场景是 **synthcity**，用户已验收部署版本并批准提交汇总 PR；尚未合并 main。契约审查记录为 [#62](https://github.com/ANetResearch/ANet-Drone4D/issues/62)。设计定义见 [设计文档](../design/scene-target-engine.zh-CN.md)，实测结果见 [验收报告](../audit/target-life/REVIEW.zh-CN.md)。

## 与 v0.2.0 的对照

比较基准为仓库 tag `v0.2.0`（`06731a8`）。本分支实际从较新的 `705a1be` 开发，以下只描述本分支增加的目标能力；两者之间的上游 D3、感知、飞行等演进不归入本次贡献。

| 维度 | v0.2.0 已有能力 | 本次增加 |
|---|---|---|
| 类别与身份 | person、vehicle、dog、uav、machine、object 六类及目标 ID | 沿用原生类别/ID，增加资产绑定、角色与描述、车型/车牌元数据；设施内隐藏后重新出现保持身份 |
| 外观 | 原生目标形体/线框与感知配置 | 28 个可选资产（12 人、7 车、6 物件、犬/叉车/四旋翼），源文件与部署内容哈希、人体/犬步态插值、部分车型轮组动画、前后物理车牌 |
| 活动 | static、path、random_walk 等目标运动配置 | 基于可达目的地的通勤、购物、返家、停靠、巡检与工作活动；设施入口、容量、室内状态和持续循环 |
| 场景约束 | 原有几何、目标配置与运动接口 | 活动条件审计、可选导航许可掩码、世界/坐标/网络版本绑定；车行/步行/空域分开准入，缺数据拒绝生成 |
| 多主体运动 | 原有单目标运动机制 | 全体实体 10 Hz 固定步进、动态避让、路口/入口路权、下游空间检查、多圆车身及转弯扫掠检查 |
| 行为生成 | 手动配置目标及运动参数 | 用户选择人口、车型和其他类别，固定 seed 生成完整群体配方；1500 秒预演准入后显式应用 |
| 定制设计 | 本次新增的可选入口 | 服务端 DeepSeek 将意图转为受限设施访问配置；同一编译/验收路径，保存结果后无需模型即可重放 |
| 原生界面 | 识别物列表、配置、相机与沙盒 | 外观/身份编辑、活动状态卡、生活生成器、近看跟随与车牌观察，以及小窗口启动/资产加载修复 |

六类识别物、稳定 ID 和整个无人机仿真并非本次从零新增。本次也不新增 benchmark query、任务评分或给被测 agent 提供隐藏真值。

## 行为与复现约定

每个实体每个固定步均参加计算。停靠、排队、购物、在室内和休息有明确状态，不采用“轮流激活少数目标、其余冻结”的预算策略。路权和动态避让会产生等待；准入同时检查移动与到访进度，不能用不动来实现零碰撞。25 分钟不要求所有目标一直行走。

固定 seed 仅在世界、坐标、语义网络、资产/实体尺寸、编译器版本和配方均锁定时保证重放。模型输出本身不承诺逐次相同；保存其结构化意图和通过验证的配方后，重放不再调用模型。模型不能下发任意代码、坐标或逐帧动作。

连续生活模式须同时启用部署配置和前端开关。预览或模型思考不会暂停已运行世界；应用新群体是显式的沙盒重置操作。功能默认可选，旧配置继续可用。

### 合入 d3-dev 时的约束（2026-10-25）

- 契约：识别物可选字段 `appearance`、`activity`、`metadata`、`life` 与 `target_detail` 的 `timeline`、`activity` 按 AWR-17 §10.2 记为契约次版本 1.3.0（只增，layouts 不变）。
- 随机数：行人活动计划的目的地与停留抽样改用登记随机流 23 `target_activity`（键 `(seed, 23, actor_key, variant)`，`actor_key` 为 `sha256(actor_id)` 前 8 字节），计划编译器版本升为 `pedestrian-activity-2`；此前生成的计划须以 `tools/deploy/targetlab/build_activities.py` 重新生成，该脚本同时更新 T8 模板中的计划哈希。生活群体配方（T9–T13）不使用随机抽样，不受影响。
- 公开构建：`VITE_AWR_DEMO=public` 且未设 `VITE_AWR_TARGET_LIFE=1` 时，生活群体生成器、行为预演与定制编排模块在构建期替换为空实现，相关文案与实验模板名从词典剔除；产物不含 `/target-life/` 路由与模型服务名称。
- 模板目录：识别物带实验绑定的模板（T7–T13）只在 `AWR_TARGET_LIFE_ENABLE=1` 的部署中列出与创建，缺省部署（含公开演示）不可见。
- D2 缺省行为：`SimCore.reset` 的慢任务仿真时钟重置只在 `AWR_TARGET_LIFE_ENABLE=1` 时启用；缺省部署的重置与调度行为与合入前一致。

## 如何复核当前版本

部署与重建命令见 [targetlab README](../../tools/deploy/targetlab/README.md)。从原生 synthcity 世界页创建 **T13 七种车型与六类目标（实验）**：12 人、7 车、2 犬、2 架巡检无人机、1 叉车、3 个固定设施，共 27 个实体。

1. 在识别物详情检查资产、活动/目的地、等待原因、到访数和移动距离；使用“近看并跟随目标”。车辆可以编辑车型相关元数据、车牌并近看前车牌。
2. 在生活生成器选择数量、车型与 seed，生成预览并检查准入结果，再显式应用。应用会重置当前沙盒。
3. T10/T11 是两份已保存的定制意图案例，可离线重建。真实模型调用必须另行配置私有凭据与预算；本次提交不含凭据。
4. 模型二进制、纹理、世界包及生成的网络/配方存放在部署目录，不进入 Git。模板引用的外部内容须同步重建/安装，不能仅复制模板 JSON。

初始人物、车辆和物件导出仍需现有 ALE 编译资产目录及其来源锁文件；其余三类资产由单独锁定的 GLB 输入导出。运行时不依赖 ALE 服务，导出工具当前尚非一键从零下载资产的分发器。来源和许可见 [第三方声明](../../THIRD_PARTY_NOTICES.md#5-optional-scene-target-assets-not-bundled)。

## 验证结果与边界

- 部署阶段后端 241 项相关功能测试通过，前端 75 项单元测试、类型检查和生产构建通过；具体范围和 PR 前复测记录在验收目录。**没有据此声称完整 `make ci` 已通过**。
- T9–T13 与另一七车型 seed 通过 1500 秒离线准入；T13 的 25 分钟真实时间长测中，27 个目标各至少更新 15000 次，26 轮全体采样与 seed 重放一致，最大观测时钟偏差 0.619 秒。
- 原生浏览器代表性检查覆盖全部六类、居民出设施、车辆再出发、无人机巡检/悬停、车牌编辑并恢复；这不是所有资产/场景的全面视觉认证。
- 已完成两次 DeepSeek 实际调用，共 6281 tokens；没有返回实际价格，未伪造费用估值。PR 整理不再调用模型。
- synthcity 之外仍需人工/适配器提供验证过的道路、步行区、支撑面、设施入口、容量和空域；不具备任意重建场景自动语义恢复能力。
- 室内用状态与隐藏表达；没有室内房间、实际上下客/搬运、足部 IK、悬挂/轮胎接触动力学。人体和犬是采样姿态插值，公交/卡车尚无轮组动画。
- Web FPV 共享原生目标图层；服务端离线图像及其他渲染器尚未完成同等资产认证。活动配方仍是内部实验接口，尚未统一到 D3 事件磁带。
- 旧 30 目标/12 无人机性能门槛在共享主机未通过：基线 8.73、本分支 8.97 ms/仿真秒，门槛 3.0。两次独立测量不是正式性能协议，不构成性能无回归声明。
- 限制资产加载并发后，90 秒实时连接复测无断线；更早两次探测曾停顿，仍需冷缓存与更长时间网络验收。

主责 M23 活动规划及 M18 目标系统；需 M00 契约、M22 场景、M08/M11 运行时与 API、M06/M15 视口与界面，以及 M25 消费面协同审查。重点确认可选 TargetCfg 字段和 target_detail 的兼容性、配方加载与完整群体导入的失败行为、连续世界与显式重置语义、资产分发和后续 D3 对齐。完整合并门禁遵循 CONTRIBUTING；本 PR 不直接合并 main。本轮已用隔离 authoring worker 修复 API 跨模块依赖，并无损分片超限数据，完整 lint 通过；托管 CI 与其余合并要求分别核验。

## 手动外观与身份配置

启用目标资产后，“新增”先选择类别，再打开配置对话框，最后点击场景放置。人物可选 12 套模型、车辆可选 7 种车型/外观并输入车牌和所属地区；犬目前只有 1 套模型，界面明确标注，不提供不存在的品种或毛色选项。已有目标默认进入“外观与身份”页，显式保存或撤销修改。角色与备注仅是元数据，不承诺自动换装。

外观、车牌、名称作为一次原子更新提交。仅编辑车牌/备注时不改变尺寸、ID、位置或活动配方。生活群体中替换模型仍需满足已准入的路线尺寸，失败显示原因；个体新增需通过生活生成器重建群体，避免出现脱离共享调度的实体。

生活预览及设施读取通过有超时、请求/响应大小限制和取消回收的独立 worker 执行；API 进程不再导入仿真编译器。正在运行的世界不随预览暂停。

### 手动外观预览（2026-10-22）

新增目标和编辑已有目标时，选择外观会在表单中显示该资产的真实网格与纹理。预览支持拖动旋转、缩放、正面/背面、重置视角；车辆输入的车牌文字立即出现在预览牌照上，并可切换车牌近景。预览是独立草稿，不写目标配置、不调整世界相机，也不暂停世界；只有保存才应用。线框选项明确显示没有精细模型，下载失败可重试。

模型和纹理由与场景共用的哈希校验加载器读取。切换模型、关闭面板会取消未完成的下载并释放预览 GPU/图像资源；预览按需重绘，不运行持续动画循环。自动取景按实际包围盒适配不同尺寸与宽高比。它展示静态外观，不是活动/步态或现场光照的预演。

### 行为预演与群体编辑说明（2026-10-22）

已有生活目标的外观表单增加 25 分钟行为预演：独立实例化同一个 `LifeWorld`，以原引擎 0.1 秒步长推进全体成员，每秒采样一次。选中目标可播放、暂停、1/10/30 倍速与拖动时间轴，查看实际轨迹、朝向、目的地、速度、累计距离、等待原因和设施内隐藏状态。模型居中展示同源步态/轮组动作，路线图表达位移；不会用来回走的示意动画替代真实行为。公交/卡车无轮组动画等原有资产限制仍在。

这是已保存配方从零开始的创作重放，不是当前现场的未来预测；外观草稿可用于观看，但不会重新规划或写入配置。预演、暂停预演与拖动时间都不控制现场时钟。首次生成后以配方哈希缓存整个群体，换目标复用缓存，不调用模型。仅路线示意图将每条道路降采样为最多 16 个二维点；仿真仍使用原始完整道路，目标样本不降采样。`POST /target-life/{sha256}/rehearsal` 是实验性操作者创作接口，后续正式 API 契约与 bench 隔离仍须统一收录；不得把该接口给予被测 agent 作为观察工具。

`27 / 30` 表示当前数量 / 原生容量上限。v0.2.0 的独立目标支持未满员新增和单独删除；生活群体的禁止单独增删、移动、停用是本分支增加的约束，以免留下继续参与交通与占用的隐形成员。列表现在以“调整生活群体”替代不可点击的新增入口，展开生成器并填入当前各类数量和已知 seed。重新生成会替换所有成员的手动外观、车牌及行为，应用后从零开始，界面明确提示；尚未实现保留全部自定义字段的成员级热增删。仅打开生成器不修改任何目标。

首次流快照为空时，保留尚未在流中出现的 REST 目标配置；已观察到再消失的成员仍清理。避免刷新时错误丢失生活绑定、短暂显示独立新增入口。

本轮验证：前端目标及 i18n 49 项通过，独立重放/缓存/场景隔离及 worker 传输 11 项通过，全仓 lint、类型检查和生产构建通过。服务器目标/活动回归 240 项通过；已有 30 目标/12 无人机性能测试仍失败（8.54 ms/sim-s，门槛 3.0），不能称完整 CI 或性能门禁全部通过。密集路网响应从超过 4 MiB 降至约 0.82 MB，缓存命中 worker 实测 2.02 秒。浏览器验收包括 27 成员预填、居民设施进入/离开、路线拖动、播放/暂停以及车辆模型与车牌保留；未应用群体替换，未修改保存配置，未调用付费模型。
