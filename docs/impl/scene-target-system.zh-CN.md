# 场景适配目标系统：相对 v0.2.0 的升级说明

本分支将原生“识别物”扩展为可选的精细外观、场景约束、持续身份和自主生活行为系统。当前完整验收场景是 **synthcity**，用户已验收部署版本并批准提交汇总 PR；尚未合并 main。契约审查记录为 [#62](https://github.com/ANetResearch/ANet-Drone4D/issues/62)。设计定义见 [设计文档](../design/scene-target-engine.zh-CN.md)，实测结果见 [验收报告](../audit/target-life/REVIEW.zh-CN.md)。

## 与 v0.2.0 的对照

比较基准为仓库 tag `v0.2.0`（`06731a8`）。本分支实际从较新的 `705a1be` 开发，以下只描述本分支增加的目标能力；两者之间的上游 D3、感知、飞行等演进不归入本次贡献。

| 维度 | v0.2.0 已有能力 | 本次增加 |
|---|---|---|
| 类别与身份 | person、vehicle、dog、uav、machine、object 六类及目标 ID | 沿用原生类别/ID，增加资产绑定、角色与描述、车型/车牌元数据；设施内隐藏后重新出现保持身份 |
| 外观 | 原生目标形体/线框与感知配置 | 28 个可选资产（12 人、7 车、6 物件、犬/叉车/四旋翼），源文件与部署内容哈希、人体/犬步态插值、部分车型轮组动画、前后物理车牌 |
| 活动 | static、path、random_walk 等目标运动配置 | 基于可达目的地的通勤、购物、返家、停靠、巡检与工作活动；设施入口、容量、室内状态和持续循环 |
| 场景约束 | 原有几何、目标配置与运动接口 | 活动条件审计、可选导航许可掩码、世界/坐标/网络版本绑定；车行/步行/空域分开准入，缺数据拒绝生成 |
| 多主体运动 | 原有单目标运动机制 | 全体实体 10 Hz 固定步进、动态避让、路口/入口路权、下游空间检查、多圆车身及转弯扫掠检查 |
| 行为生成 | 手动配置目标及运动参数 | 用户选择人口、车型和其他类别，固定 seed 生成完整群体配方；1500 秒预演准入后显式应用 |
| 定制设计 | 本次新增的可选入口 | 服务端 DeepSeek 将意图转为受限设施访问配置；同一编译/验收路径，保存结果后无需模型即可重放 |
| 原生界面 | 识别物列表、配置、相机与沙盒 | 外观/身份编辑、活动状态卡、生活生成器、近看跟随与车牌观察，以及小窗口启动/资产加载修复 |

六类识别物、稳定 ID 和整个无人机仿真并非本次从零新增。本次也不新增 benchmark query、任务评分或给被测 agent 提供隐藏真值。

## 行为与复现约定

每个实体每个固定步均参加计算。停靠、排队、购物、在室内和休息有明确状态，不采用“轮流激活少数目标、其余冻结”的预算策略。路权和动态避让会产生等待；准入同时检查移动与到访进度，不能用不动来实现零碰撞。25 分钟不要求所有目标一直行走。

固定 seed 仅在世界、坐标、语义网络、资产/实体尺寸、编译器版本和配方均锁定时保证重放。模型输出本身不承诺逐次相同；保存其结构化意图和通过验证的配方后，重放不再调用模型。模型不能下发任意代码、坐标或逐帧动作。

连续生活模式须同时启用部署配置和前端开关。预览或模型思考不会暂停已运行世界；应用新群体是显式的沙盒重置操作。功能默认可选，旧配置继续可用。

## 如何复核当前版本

部署与重建命令见 [targetlab README](../../tools/deploy/targetlab/README.md)。从原生 synthcity 世界页创建 **T13 七种车型与六类目标（实验）**：12 人、7 车、2 犬、2 架巡检无人机、1 叉车、3 个固定设施，共 27 个实体。

1. 在识别物详情检查资产、活动/目的地、等待原因、到访数和移动距离；使用“近看并跟随目标”。车辆可以编辑车型相关元数据、车牌并近看前车牌。
2. 在生活生成器选择数量、车型与 seed，生成预览并检查准入结果，再显式应用。应用会重置当前沙盒。
3. T10/T11 是两份已保存的定制意图案例，可离线重建。真实模型调用必须另行配置私有凭据与预算；本次提交不含凭据。
4. 模型二进制、纹理、世界包及生成的网络/配方存放在部署目录，不进入 Git。模板引用的外部内容须同步重建/安装，不能仅复制模板 JSON。

初始人物、车辆和物件导出仍需现有 ALE 编译资产目录及其来源锁文件；其余三类资产由单独锁定的 GLB 输入导出。运行时不依赖 ALE 服务，导出工具当前尚非一键从零下载资产的分发器。来源和许可见 [第三方声明](../../THIRD_PARTY_NOTICES.md#5-optional-scene-target-assets-not-bundled)。

## 验证结果与边界

- 部署阶段后端 241 项相关功能测试通过，前端 75 项单元测试、类型检查和生产构建通过；具体范围和 PR 前复测记录在验收目录。**没有据此声称完整 `make ci` 已通过**。
- T9–T13 与另一七车型 seed 通过 1500 秒离线准入；T13 的 25 分钟真实时间长测中，27 个目标各至少更新 15000 次，26 轮全体采样与 seed 重放一致，最大观测时钟偏差 0.619 秒。
- 原生浏览器代表性检查覆盖全部六类、居民出设施、车辆再出发、无人机巡检/悬停、车牌编辑并恢复；这不是所有资产/场景的全面视觉认证。
- 已完成两次 DeepSeek 实际调用，共 6281 tokens；没有返回实际价格，未伪造费用估值。PR 整理不再调用模型。
- synthcity 之外仍需人工/适配器提供验证过的道路、步行区、支撑面、设施入口、容量和空域；不具备任意重建场景自动语义恢复能力。
- 室内用状态与隐藏表达；没有室内房间、实际上下客/搬运、足部 IK、悬挂/轮胎接触动力学。人体和犬是采样姿态插值，公交/卡车尚无轮组动画。
- Web FPV 共享原生目标图层；服务端离线图像及其他渲染器尚未完成同等资产认证。活动配方仍是内部实验接口，尚未统一到 D3 事件磁带。
- 旧 30 目标/12 无人机性能门槛在共享主机未通过：基线 8.73、本分支 8.97 ms/仿真秒，门槛 3.0。两次独立测量不是正式性能协议，不构成性能无回归声明。
- 限制资产加载并发后，90 秒实时连接复测无断线；更早两次探测曾停顿，仍需冷缓存与更长时间网络验收。

## 维护者审查重点

主责 M23 活动规划及 M18 目标系统；需 M00 契约、M22 场景、M08/M11 运行时与 API、M06/M15 视口与界面，以及 M25 消费面协同审查。重点确认可选 TargetCfg 字段和 target_detail 的兼容性、配方加载与完整群体导入的失败行为、连续世界与显式重置语义、资产分发和后续 D3 对齐。完整合并门禁遵循 CONTRIBUTING；本 PR 不直接合并 main。PR 前完整 lint 发现生活 API 跨模块依赖及上游既有超限文件，详见验收报告；当前不能标为合并门禁通过。
