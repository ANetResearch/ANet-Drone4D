## 0. 摘要

1. **时钟档**（ADR-090）：`d1_250`（250 Hz、4 ms、L1 每 2 tick）与 `sandbox100`（100 Hz、10 ms、L1 每 tick）；进程生命周期内不可变，取自
   `FleetConfig.clock_profile` 或 `AWR_CLOCK_PROFILE`；SimClock、流水线、checkpoint、输入日志、resim、meta 与 caps 全部按档位；stage 可按 `hz`
   登记，按档调度表与预算表（sandbox100 Σ 含主循环项 0.154 ≤ 0.16）在构建期解析并校验。d1_250 的 M08-AC-004 golden 不变。
2. **实体层**（ADR-098）：`EntityTables["target"]`（容量 32、会话上限 30 → 505），插件经 `register_entity_block` 登记列；识别物进入 roster
   （`kind = target`），`tap_targets` 以 TargetLite32 发布 `state/sim-core/targets`（10 Hz）；参与 checkpoint。
3. **固定翼宿主**：`frame_kind` 列、`Fidelity.FW = 16`、`write_kinematic`（numba）、VTOL `set_fidelity`、按构型分派命令与安全动作给 M21 的运动提供者、
   伞降触地判据；功率模型注册表与分派助手（多旋翼回退模型与 D1 一致）。
4. **机型目录**：P600 profile 2.0.0（用户规格，docs/20 §3）与 v1 存档 `p600_mid360@1.0.0`；`catalog.json` 装载、schema 1.1 按构型检查、MNT-1、
   插件登记的机型检查、会话克隆（白名单与界限、`<id>_c<n>`、522 逐项原因）；限速档 6 列（追加 MPC_Z_VEL_MAX_UP/DN）。
5. **命令**：`loiter`（多旋翼映射 ORBIT）；`gimbal`、`zoom`、`sensor/mode` 机体命令路由（M08 做准入 ④⑤⑦ 后交 M13）；`fleet/update`；第 ⑥ 步
   参数检查登记；手动控制时钟锁（FR-220）。
6. **运行时**：批处理自由运行（确定性，固定规划延迟，退出码 0/3）；tap 空载优化与 perf 自报（`cost_core_per_rate`）；会话配置的冷启动装配、
   `sim/reset{sandbox_config}` 与快照导出；预热进程的接替载荷（P1）；沙盒机队实例的查询（instances、vehicle_state、vehicle_sensors）。
7. **REST**：`rest/fleet.py` 改为 `ctx_for`，导出 `sandbox_router`（SB-28 至 SB-37）。
8. **工具**：`tools/vehicles/lowpoly.py` 固定翼与 VTOL 低模（两档 mesh）；`fleet_ladder` 的 `--clock`、`--targets`、`--perception`。
9. **集成**：按其他工作包给 M08 的请求接入 M07 会话配置、M13 挂载与传感器查询、M04 几何核预热、兴趣下推 `streams`、`AWR_DETACHED` 等（§3）。

## 2. 设计要点

1. **档位是进程常量**。`clock_profile.current()` 只在 SimCore 构造与 stop 时切换（stop 恢复先前档位，避免同一测试进程内的档位泄漏）；
   stage 内一律读 `ctx.dt_tick`、`ctx.stage_dt`、`ctx.clock.tick_ns`，`pipeline.TICK_NS`、`main.TICK_NS` 只保留为 d1_250 的兼容名。
2. **调度表优先**。D1 插件的登记代码不变即可在 sandbox100 下运行：表中列出的 stage 用表项；新 stage 可用 `hz=` 登记；两者都没有时构建失败，
   不会静默按 d1 节拍跑出 2.5 倍的步长误差。
3. **实体层与 FleetState 分离**。识别物不占机体 slot、不进入租约与 DroneAdapter；列由插件登记、按 `target_no` 升序处理（ADR-049 确定性）；
   发布只按冻结布局打包，不解释语义。
4. **固定翼"宿主"而非"实现"**。M08 只给状态写入、保真度位、分派与触地判据，固定翼动力学、导航与安全动作全部在 M21；没有提供者时命令 109、
   安全动作退回多旋翼（只在测试与过渡期出现）。
5. **组合根边界**。M08 不静态导入插件包；与 M13、M07 的接线一律按模块名（`sys.modules`）或鸭子类型（`ctx.env.configure_session`），
   插件未装配时行为与 D1 相同。
