# M23 场景适配目标引擎：第一批

基线 `705a1be`；设计与后续批次见 [场景适配目标引擎](../design/scene-target-engine.zh-CN.md)。

## 已实现

- `scene-audit --world`：只读核对世界与坐标文件哈希、锚点 schema/世界绑定/唯一身份、确认状态、覆盖范围和导航层声明；报告文件哈希与未满足条件。
- `build_nav(..., allowed_mask=...)`：许可栅格与原几何约束求交后做车辆腐蚀，空许可绝不退回无约束导航；默认旧行为保留。
- `audit_nav`：连通分量面积、最大分量占比、指定端点所属分量与点对连通性。无自动吸附。

这是内部基础能力。当前编译器没有自动接入许可掩码；真实路网适配、地面分层、精细资产、生活活动模板、Web 面板和 DeepSeek provider 均尚未交付。
审计明确阻止把“文件存在”当成真实行为就绪，不替代世界包校验器，不授予实际场景可运行证明。
