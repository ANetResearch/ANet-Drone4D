## 2. 设计要点

1. **一个数组核**：纯函数与管线共用 `level.evaluate`（按对向量化，焦距可按对给出），保证 sim-core 判定、M20 规划与 TS 计算器同一公式；
   管线的路径透过率取 M07 `optical_depth`（指数霾、雾层、降水），纯函数按 MOR 均匀消光。
2. **视线只给值得看的对**：视锥、像素、环境三级门控在视线之前；未请求视线的对（n_max 低于门限）`k_los` 记为 1（不参与限制因素）。
3. **公平的射线分配**：共享令牌桶每 tick 只补约 2.4 条，按 `slot % 片数` 固定分片时同几架机在每个周期都恰好遇到令牌不足而长期得不到视线
   （12 机实测 2 架饿死）。改为周期内均匀分布、逐周期错开一位，并在每机的候选列表上自第一个延期的对接续轮转。
4. **对状态以 (agent_no, 传感器名, target_no) 为键**：target_no 不复用，行复用与 id 复用都不会带入旧状态；识别物或机体消失时 5 Hz 清理；
   时钟回退（剧本重置、恢复快照）清空全部状态（检测环 seq 保持单调）；成像传感器关闭或卸下后，其已有的对按视锥外继续计时（2 s 后
   `capture_lost{reason: fov}`），不会停留在 CAPTURED。
5. **非成像只引导不捕获**：雷达、声阵列、MID-360 的检测进入航迹（声阵列除外）与 `best_level`，不构成明确捕获；雷达与声阵列不外露识别物 id。
6. **前端分层**：engine 无框架依赖，msgpack 只在 net/（`decodePerception` 接受注入的解码器）；store 只读，Toast 由 M15 `d2Notices` 按同一 30 s 窗口发出。

## 3. 偏差

| # | 条款 | 偏差 | 理由与处置 |
|---|---|---|---|
| 1 | PRD §6.7 `R_nir = …·tau_850(R)` | 采用不动点 `tau_850(R_nir)`（AWR-20 §6.3、M13 `IllumSpec.range_m` 同一口径），以二分求根（浓雾下 sigma·R_nir > 1 时简单迭代振荡） | 与 AWR-20 §6.9 表逐格一致（τ 取识别物斜距时 nir_ill_l 3 km 的 I 级偏大 3%）；已提文档总编第 1 条 |
| 2 | PRD §6.9 分片"slot % 20 == k" | 机体在周期内均匀分布并逐周期错开（`PerceptionRuntime.shard_slots`），每机仍每周期一次（5 Hz，间隔 0.18–0.22 s） | 固定分片使部分机体长期得不到视线（§2 第 3 条）；已提文档总编第 3 条 |
| 3 | PRD §6.12 RNG 通道 `64·sensor_no + target_no` | `((sensor_no << 16 \| target_no) << 3) + j` | target_no ≥ 64 时原式与下一传感器重叠；已提文档总编第 4 条 |
| 4 | AWR-04 §9.2 表（狗 `nir_ill_l` 242–370 / 242–315） | 黄金表中不可行（`keepout_gt_range`） | PRD §6.13 规定运动识别物 `v⊥ = speed_max`（狗 8 m/s），1/30 s 曝光下残余模糊使 N·k_blur < 14 px；WP-01 要求确认口径，按 PRD 保留；LWIR 100 mm 264 m（表 275 m）同因。其余 geometric 行与表 ±3% |
| 5 | AWR-04 §9.2 physical 行 | 黄金表 physical 行用 M18 `keepout_volumes`（配置体 ∩ 准则体、保守口径，截断到 radius_max），下界与表不同（如 P600 夜间盯人 153.5 m） | M18-FR-016 的定义；表按未截断的 r_ac；已提文档总编第 2 条 |
| 6 | PRD §4.2 FR-018、§7.3（检测环 2048、每传感器 16 个） | 8192、8 个 | 17 §17.6.4 与契约 `maxItems` 为定义方 |
| 7 | PRD §6.7 曝光 | 按照度（E ≥ 50 lx 且非 NIR 为 1/1000 s），不读 M13 的按模式曝光 | 与纯函数、TS 计算器一致；M13 口径在 50–400 lx 不同，已提 M13 与文档总编 |
| 8 | PRD §6.8 雷达量测 | 方位与俯仰输出 World ENU（不是安装系） | 与 M13 `cue` 约定一致、可直接引导；已提文档总编第 7 条 |
| 9 | PRD §6.6 雷达 `γ_rain = 0.9·RR^0.75` | 取型号库 `rain{k: 1.0, alpha: 0.7}`（AWR-20 §6.5） | 型号库为定义方（10 mm/h：151 → 约 139 m 与 AWR-20 一致） |
| 10 | FR-015 的 562 | 只在 SB-67（服务端可行窗口）中给出（任何距离都达不到所需等级时） | 帧与 detail 无错误码字段；帧中的 `limiting = pixels` 与 `n_req` 给出同样信息 |
| 11 | PRD §6.12 cue 缺省策略 | `payload.cue` 未设时按 M20 `set_cue(uav, on)`，缺省 off | 任务归属在 M20；M20 设置后生效 |
