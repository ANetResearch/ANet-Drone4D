### 1.2 `apps/web/src/stores/timeline.ts`

字段沿用 M15-S 骨架（只增加 `canWrite`、`buffering`、`followLive`、`recording`、`indexLoading`、`notice`）。一个 overlay 相位任务（Tier S 4 Hz、
B/A 10 Hz）读 engine/time 门面并合并为一次写入：TIME 摘要、所见时刻 `tDisplayS`（= tRender）、范围、实时视窗跟随、待确认超时、RTF 徽标、
选中机高度序列（4 Hz）、回放区间（回滚重跑、抽取、缺口、已预读）、HERO（250 ms）与数据版本号；浏览器冒烟实测 ≤ 4.5 次/s（含用户动作）。
动作：`play`、`pause`、`togglePlay`（ENDED 时从头播放）、`setRate`、`step`（实时 sim/step；回放自动映射为 seek）、`seek`（乐观播放头、
100 ms BUFFERING、PENDING 期间合并为最终目标、首个新纪元样本记 `lastSeekMs`）、`zoom`/`fit`/`pan`、`jumpMarker`、书签增改删（operator/admin
经 REST，viewer 存 localStorage `awr.bm.<run>`）、`openReplay`（open → meta、段信息、缺口、`.ovw`/`.evx`、书签、可选 seek）、`closeReplay`、
`setNotifier`、`clockFacts`。事件标记来自 `event` 通道、`GET /api/events` 补拉与录制中当前段 `.evx`。回放命令串行化并等待同 request_id 的终态
（seek 等 did_seek、open 等非 opening）。测试构建暴露 `window.__timeline`。

## 3. 与 PRD 的偏差及理由

| 偏差 | 理由与影响 |
|---|---|
| `sampleOne(agentNo, tS, out: DronePoseSoA, o)` 取代 §7.1 的单对象 `DronePose` | M06 已按 SoA 签名接入（M06-to-M12 第 1 条），零分配且复用同一采样核；语义不变 |
| D_wall 的首个有效测量直接初始化，不从 300 ms 按 10 %/s 下降 | 避免连接后约 4 s 的额外延迟；之后的变化全部受 1 s 平滑、10 %/s、5 % 迟滞约束（AC-003 测试逐帧验证） |
| recorder 以 LOSSY 读者 drain（M11-R-to-M12 建议 LOSSLESS） | PRD P-09、FR-031 要求 recorder 绝不反压 sim-core；覆盖时以 `recorder.gap` 与 meta.gaps 记录 |
| meta.json 逐段补充字段写在顶层（`sidecars{"<k>": …}`、`gaps[{segment…}]`、`detail_coverage`、`speed_max`、`events_per_sim_s`、`source`） | 契约 `segments[]` 为 additionalProperties: false；已请 M00 登记后移回段内 |
| 书签文件只写契约现有字段（`created_by` 写为 `principal_id`，不写 `epoch`、`source`、`run_id`） | 契约 `rec/markers.schema.json`；草案见 `M12-drafts/rec/bookmarks.schema.json`；"位于回滚重跑区间"可由段谱系按时刻判断 |
| markers 表两端各自内置（草案与 `tests/recorder/fixtures/markers.json` 对拍） | `packages/contracts/rec/markers.json` 属 M00，尚未登记与生成 |
| `perf/rec` 指标只进日志与 `ctl/recorder/status` 回复 | bus key 未登记（KEY-01 禁止字面量）；已请 M00 |
| `state/replay/{agents,tasks}` 未发布（S3 ext） | key 未登记（F-09）；agent 状态照常录制到 `/agent/**` |
| 无剧本（`AWR_SCENARIO` 未设置或文件缺失）时不自动开录 | PRD 的 `record` 缺省 true 针对已加载的剧本；骨架与开发会话避免无意识占用磁盘；`AWR_REC_AUTOSTART=1` 可强制 |
| 谱系 `restored_t` 取同一 drain 轮已收到的 `sim.restarted`，否则取新纪元第一帧时刻 | §6.6.5 的"1 s 内等待事件"会推迟 FLUSH 与谱系写入；两者只差一个 tick |
| ColumnAgg 在一次调用中完成（未在 LfScheduler 空闲片分块） | 50 万标记的 Node 基准待性能验收；超预算时再分片（接口不变） |
| `.ovw` 统计取 bin 内最后一个块、轨迹取块中行（不取 Full64） | 重建只依赖 MCAP 内容且逐字节一致；块节拍 25 Hz 下 1 s bin 的差异可忽略 |
| `mk/m12.mk` 未创建 | 不在本工作包路径（任务书路径清单）；已请 M00 |
| RESET channel 到生产者区段的映射经同槽 Full64 与 roster 推断 | 槽中只有 channel id；已请 M11-net 在槽中补 agentNo |
| 环境锚点相位（AC-048 环境部分、seekPhase 中 S、D 的 1e-6 m）未在本模块测试 | 锚点推进属 M07（Python 与 TS 同式实现已存在）；本模块保证 backfill 关键帧逐字节一致 |
