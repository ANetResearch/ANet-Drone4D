## 1 复核范围与方法

1. 两种语言各自 `sphinx-build -W --keep-going`（`make docs-site`）与模拟 Read the Docs 环境（`READTHEDOCS=True` 直接调用 `sphinx-build -W`）各构建一次。
2. 对照 `.readthedocs.yaml`、`docs-site/zh_CN/.readthedocs.yaml`、`_shared/conf_common.py`、`_shared/_ext/drone4d_site.py`、`_shared/_templates/*.html`、`_shared/_static/css/drone4d.css` 核对 Read the Docs 目录布局、根跳转、语言与版本切换、左上角标志与配色，并与 `apps/web` 的品牌锁与主题色核对字节级一致性。
3. 用 `node tools/lint/check-brand.mjs`、手工扫描 Unicode 范围核对 emoji/禁用字形与感叹号（企业语气）。
4. 对 `https://docs.scrapy.org/en/latest/` 取结构摘要，与文档站首页对照。
5. 在 `scratchpad/docs-review-clone/` 用 `git clone https://github.com/ANetResearch/ANet-Drone4D.git` 重新克隆，检出 `v0.2.0`，按 `docs-site/en/intro/quickstart.md` 逐步执行到共享展示与（`AWR_PROFILE=sandbox`）沙盒会话跑起，并用文档给出的 Python SDK 示例脚本创建会话、加机、读状态、结束会话，端口用 `AWR_PORT_OFFSET=31`。
6. 对照 `docs/04-D2-设计增补与决策记录.md`、`docs/impl/D2-验收报告-第2轮.md`、`docs/impl/D2-ACC-2-报告.md`、`apps/web/src/app/i18n/{zh-CN,en}.json` 核对文档站引用的数字、结论与界面用语。
7. `make docs-site-linkcheck` 核对两种语言全部外部链接；全文扫描邮箱、token、密钥样式字符串。

## 5 偏差说明

1. **端口偏移。** 任务书给出"端口偏移 950"，但本项目 `net.port_offset`（`AWR_PORT_OFFSET`）的取值范围为 0–31（`python/awr/runtime/config.py` 校验 `ge=0, le=31`，超出按退出码 2 拒绝），无法表达 950。复核改用 `AWR_PORT_OFFSET=31`（端口 8310/8311/8312/7757/5483），与本机其他进程占用的端口（8931、9993、35651、39811、43811 等）互不冲突。
2. **未删除共享的 numba 编译缓存。** `~/.cache/awr/numba` 不属于任何一次克隆，复核期间的编译产物与本机其他正在运行的并行任务共用同一缓存路径；为避免影响其他任务的运行中进程，未按 `D2.2-D1-报告.md` 的做法逐一清理新增缓存目录，只清理了属于本任务的克隆目录与临时日志文件。
3. **未独立复现跨城市切换。** 见第 2.6 节说明：隔离克隆按许可要求不含 UrbanScene3D 数据，只能构建 `synthcity`，因此第 3 节第 1 条的结论建立在用户反馈与并行工作包报告的互证，而非本任务独立执行的端到端跨城市复现。
4. **未处理用户本轮同时提出的"在其他地图中加入模拟的无人机监测任务和对应目标物"的请求。** 该请求与"切换城市"缺陷同时提出，但按本任务的性质（对抗式复核、不改代码）与范围（docs-site/），不包含修复产品代码或新增场景内容；复核期间读取到 `docs/impl/D2.2-W1-报告.md` 第 7 节已将其列为"下一任务（城市演示）"并给出接入接口说明，另外发现 `scenarios/` 目录下已有六城的 `d22-<city>-watch.json` 草稿文件（创建于 16:34–16:45 UTC，晚于 W1 报告的完成时间），显示该后续任务可能已在并行进行；本任务未对这些文件的内容或完整性做核实，仅作为范围说明记录在此，供编排方确认归属与进度。
