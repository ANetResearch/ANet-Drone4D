## 3. 与 PRD 的偏差及理由

1. **UI-only 测试构建**：共享树中视口在并行修改期间挂载即抛错（M06、M05 半成品：`reading 'query'`、未存在的 `./layers/*`），`perf/m15/smoke.spec.ts` 的失败与 M15 无关。为让 UI 可测，新增仅测试构建生效的 `?viewport=off`（不挂 WorldCanvas，M15 自行启动 loop 与默认订阅）、`?reveal=shell`（只等 shell 与 canvas 两道门）与 `build-ui.mjs --stub-viewport`（桩视口）。生产构建不含这些分支。视口稳定后应以完整视口复跑 smoke 与 layout-probe。
2. **时间轴控制**：TimelineBar 与快捷键只调用 M12 `timeline.togglePlay / step / setRate`，M12 目前仍是桩，尚未发出 `sim/*`；时钟与时间轴读数暂直接取 `RtClient.onTime`（10 Hz），不是 M12 的 `tDisplayS`。`LfTimelineTrack` 仍用 `emptyTrackModel()`，等待 M12 导出 `trackModel`。
3. **GoTo 悬停预览、相机移动关闭 Popover、视口一处红的绘制** 依赖 M06 门面（`pick.hover`、`camera.onMoved`、`drones.setRedOwner` 实现），UI 侧已接线；`sendGoto` 目前只传 `speedMps`（`route`、`altAboveHitM` 待门面扩展）。
4. **添加 / 移除 P600**：添加调用 `POST /api/fleet/vehicles`（后端尚未确认实现）；移除用本包 `fleetRest.ts` 自拼 DELETE（`net/api.ts` 无 `apiDelete`）。
5. **申请控制**：已改用 M11 的 `rt.reauthenticate`，但仍自行 POST token，以取得 409 的 `holder_since` 详情（`getToken` 409 时静默退回 viewer）。
6. **帧间隔分布卡**：以 F1 rung 条形实现直方图（`LfHistogram` 复用 LfBarRank 画法），未单独实现 F14 专用绘制。
7. **报告页**：覆盖 `awr.perf.report.v1` 可推导的章节；schema 不含逐帧时间序列，dumbbell / tickbox 图以表格与 rank 条代替。
8. **DroneRail 高度**：显示 ENU U（世界 z），不是 AGL（fleet store 无地面高度字段）。
9. **环境数值**：`stores/env` 仍为骨架（NaN），面板显示"—"；写命令已按 M07 §8.1 发出。
10. **`mk/m15.mk`**：新增 `ui-m15` 目标（03 §4.3 规定的 M15 扩展点）。
11. **事件缺口补拉**：M11 新增的 `rt.onEventGap`（页面隐藏后补拉 `/api/events?since=`）与 `rt.onError` 未接入，列为遗留。
