## 1. 结论摘要

1. 多智能体协同领域可归纳为 12 个主要问题族：任务分配（TA）、联盟形成与动态组队（CF）、多智能体路径规划（PF）、覆盖与搜索（CS）、共识与信息融合（IF）、协同跟踪（TR）、编队与避障（FO）、通信感知规划与连通性维护（CC）、追逃（PE）、分布式约束优化（DC）、MARL（RL）、LLM 多智能体（LM）。
2. 各族的经典基准普遍隐含三项理想化假设：真值观测、可靠通信、离散或抽象动力学。把这三项做成可调配置轴，可以在同一实例上度量"理想与现实之间的差距"。
3. 公共实例库分布极不均衡：MAPF 有 MovingAI 等成熟库，路径与调度有 CVRPLIB、Solomon 等运筹学实例；任务分配、联盟形成、覆盖搜索、共识融合、通信感知规划、追逃、DCOP 均缺少被广泛采用的多机器人公共实例库，论文多使用自建随机实例。这是标准问题库的主要机会。
4. 指标普遍只覆盖"算法质量"，缺少"系统层"指标（通信开销、感知不确定、容错、协作贡献）。去中心化与通信开销应作为一等指标，与解质量共同进入资源–效用支配分层。
5. 协作贡献应以干预对照度量，而不是归一化比值：早期常见的 `Δ_coop = (J_indep − J_coop) / J_indep` 在基线接近 0 时不稳定、且未指明干预对象；D4 采用零通信参考、阻断投递、载荷置换与集中式参考组成的 Δ 族（见概念设计 §8.5）。
6. 标准问题库按"问题族 × 难度 × 规模 × 网络档 × 保真度"五维组织；难度以客观旋钮（任务/智能体比、约束紧度、遮挡率、预算比、智能体密度）定义；每族保留与公开基准对齐的锚点实例，作用类似聚类研究中的 Iris。
7. D4 首批问题族为 TA、CS（含跨平台交接）、IF，以 RobustCoord 扰动协议横切；CF 作为 TA 的高阶层；PF 与 TR 在后续阶段接入。

## 2. 通用框架

### 2.1 实例的通用形式化要素

每个问题族的实例可抽象为元组 `I = (W, A, T, E, N, O, G, S)`：

| 要素 | 含义 |
|---|---|
| `W` 世界 | 几何、地图、障碍、地形与建筑、坐标系、时间基准 |
| `A` 智能体集合 | 类型（旋翼、固定翼、车、船、固定传感器）、动力学与能力、载荷、能量、初始状态 |
| `T` 任务或目标集合 | 静态或动态；到达时间、截止时间、位置、需求、价值、依赖关系 |
| `E` 事件流 | 外生事件（Canonical Event Tape）与反应事件，保证可复现 |
| `N` 通信网络 | 拓扑、带宽、时延、丢包、范围、干扰 |
| `O` 观测模型 | 传感器、噪声、视场、遮挡 |
| `G` 目标与约束 | 主指标、次指标、硬约束（安全、能量、通信） |
| `S` 种子与评测协议 | 种子集合、预算（时间、消息、算力）、重复次数 |

### 2.2 通用度量

| 度量 | 定义 | 备注 |
|---|---|---|
| 成功率 | `SR = (1/n) Σ 1[success_i]` | — |
| 相对最优间隙 | `gap = (J − J*) / J*` | `J*` 为精确解或已知下界；无法获得时用最佳已知解（BKS）并显式标注 |
| 通信开销 | 消息数 `M`、字节数 `B`、单位任务字节数 `B/|T|`、有效载荷占比 | 应计入头部、复制、转发与分片 |
| 公平性 | Jain 指数 `F = (Σ x_i)² / (n Σ x_i²)` | Jain, Chiu, Hawe, DEC-TR-301, 1984 [待核实] |
| 性能剖面 | `ρ_s(τ) = |{p : r_{p,s} ≤ τ}| / |P|`，`r_{p,s} = J_{p,s} / min_s J_{p,s}` | Dolan & Moré, Math. Programming 91(2):201–213, 2002 [待核实]；用于跨实例聚合 |
| 稳健聚合 | 四分位均值（IQM）、最优性间隙 | Agarwal 等, NeurIPS 2021 [待核实]；不得单独使用，须与均值和失败率并报 |

统计规范：主指标与次指标分离；以场景配置为统计单位，场景内对外生种子与重复取均值，层次自助法给出置信区间；同一场景不同种子不是完全独立样本（详见 `research-ns2-leaderboard.md` §5）。

### 2.3 "聚类类比"：可比性的三要素

聚类研究的可比性来自三要素：标准数据集（UCI Machine Learning Repository；Iris、Wine、MNIST 等）、公认指标（外部指标 ARI、NMI，内部指标 Silhouette、Davies–Bouldin）与公认基线（K-Means、层次聚类、GMM、DBSCAN、谱聚类）。多智能体协同领域已有若干孤立的实例库（MovingAI、CVRPLIB、SMAC 等），但存在三类缺口：

1. 实例库按问题族分散，彼此没有统一的模式（schema）；
2. 绝大多数实例是 2D 栅格或抽象图，缺少 3D 几何、真实传感器误差与受限通信；
3. 指标只覆盖算法质量，缺少系统层指标。

标准问题库的定位即补足这三点。

## 3. 问题族

### 3.1 多机器人任务分配（TA）

**形式化**

- Gerkey & Matarić 三轴分类（IJRR 23(9):939–954, 2004 [待核实页码]）：单任务机器人或多任务机器人（ST/MT）、单机器人任务或多机器人任务（SR/MR）、即时分配或时间扩展分配（IA/TA）；ST-SR-IA 等价于最优指派问题。
- iTax（Korsah, Stentz, Dias, 2013 **[已核]**）引入任务间依赖：无依赖 ND、调度内依赖 ID、跨调度依赖 XD、复杂依赖 CD，并映射到指派、VRP、带时间窗的取送与调度等运筹学模型。
- 时间与顺序约束分类：Nunes, Manner, Mitiche, Gini, RAS 90:55–70, 2017 [待核实页码]。
- 要素：能力向量 `c_i`；任务需求 `r_j`、位置 `p_j`、时间窗 `[e_j, l_j]`、价值 `v_j`；依赖有向图 `D`；效用 `u(a_i, t_j)` 或路径成本；分配矩阵 `x_ij ∈ {0, 1}`。典型目标 MiniSum、MiniMax、MiniAve（Lagoudakis 等, RSS 2005 [待核实]）。

**实例字段**：`agents[{id, type, pos0, speed, capacity, capability_vec, energy}]`、`tasks[{id, pos, demand, time_window, service_time, value, deadline_type, required_agents, required_capability}]`、`precedence_edges`、`cost_model`、`arrival_process(static | poisson(λ) | scripted_tape)`、`communication_profile`、`replan_policy`、`objective`。

**指标**：总成本 `J_sum`；工期 `J_max`；平均完成时间 `J_ave`；完成率 `CR`；期限违约率 `VR`；总价值 `V`；最优间隙；稳定性 `reassign = Σ_t |{j : owner_t(j) ≠ owner_{t−1}(j)}|`；公平性；去中心化指标（收敛轮数、消息数、冲突率、断连后的恢复时间）。

**基线**

| 基线 | 出处 |
|---|---|
| 匈牙利算法（集中式最优，`O(n³)`） | Kuhn, NRLQ 2:83–97, 1955；Munkres, J. SIAM 5(1):32–38, 1957 [待核实] |
| 拍卖算法 | Bertsekas, Annals of OR 14:105–123, 1988 [待核实] |
| 连续单项拍卖 SSI | Koenig, Tovey, Lagoudakis 等, AAAI 2006, pp.1625–1629 **[已核，据评审检索]** |
| Contract Net | Smith, IEEE Trans. Computers C-29(12):1104–1113, 1980 [待核实页码] |
| 市场方法综述 | Dias, Zlot, Kalra, Stentz, Proc. IEEE 94(7):1257–1270, 2006 [待核实页码] |
| CBAA/CBBA（拍卖 + 共识；收敛性依赖连通网络与可靠送达） | Choi, Brunet, How, 2009 **[已核]**；异步变体 ACBBA [待核实] |
| 绩效影响（PI）分布式方法 | Zhao, Meng, Chung, IEEE Trans. Cybernetics 46(4):902–915, 2016 [待核实] |
| MILP 与调度 | Gombolay, Wilcox, Shah, IEEE T-RO 34(1):220–239, 2018 [待核实] |
| 注意力模型 VRP 求解器（学习式） | Kool, van Hoof, Welling, ICLR 2019 [待核实] |

**实例库**：OR-Library（Beasley, JORS 1990 [待核实]）；CVRPLIB（Uchoa 等, EJOR 257(3):845–858, 2017 [待核实]；http://vrp.galgos.inf.puc-rio.br/ ）；Solomon VRPTW（Operations Research 35(2):254–265, 1987 [待核实]）；Gehring & Homberger 大规模 VRPTW；Li & Lim PDPTW；团队定向越野（Chao, Golden, Wasil, EJOR 1996 [待核实]）；QAPLIB。多机器人专用的公共基准基本缺位（[待核实]）。

**3D 城市、真实传感器与受限通信下的新难点**

1. 代价不再是欧氏距离：建筑绕行、禁飞区、风场与能量模型使代价须由 3D 路径规划器产生，计算昂贵。
2. 任务由观测"发现"，存在虚警与漏检，分配对象是 Belief 而非真值。
3. CBBA 的收敛保证依赖连通网络与可靠送达，在分区与丢包下可能出现重复分配或任务遗漏，需要度量"不一致窗口"。
4. 动态到达、能量约束与返航使问题成为带资源约束的在线问题。
5. 异构能力与多机协同任务（SR → MR）需要联盟（§3.2）。

### 3.2 联盟形成与动态组队（CF）

**形式化**：特征函数博弈 `(A, v)`，`v : 2^A → ℝ`；联盟结构 `CS = {C_1, …, C_k}` 为 A 的划分；最优联盟结构生成（CSG）`CS* = argmax Σ_{C∈CS} v(C)`。任务绑定型中每个联盟服务一个任务，`v(C, t)` 取决于能力覆盖 `∪ c_i ⊇ r_t`、空间位置与时间窗。动态性包括成员加入与离开、任务到达、通信约束下的联盟稳定性。

**实例字段**：`agents[{id, capability_vec, pos, comm_range}]`、`tasks[{id, demand_vec, pos, window, value}]`、`value_function(additive | synergy | submodular | oracle)`、`constraints{max_coalition_size, spatial_radius, connectivity_required}`、`dynamics{agent_failure_rate, task_arrival}`。

**指标**：结构价值 `V(CS)`；相对最优比 `V(CS)/V(CS*)`；核违反度 `ε_core = max_{S⊆A} (v(S) − Σ_{i∈S} x_i)`；联盟重组次数 `reorg`；被服务任务比例；平均联盟规模；联盟内通信连通率；以几何或语义聚类为基线时，可联合使用 Silhouette（Rousseeuw, 1987 [待核实]）、ARI（Hubert & Arabie, 1985 [待核实]）、NMI 与组队后的任务完成指标。

**基线**：Shehory & Kraus, AIJ 101(1–2):165–200, 1998 [待核实页码]；Sandholm 等, "Coalition structure generation with worst case guarantees", AIJ 111(1–2):209–238, 1999 [待核实]；综述 Rahwan, Michalak, Wooldridge, Jennings, AIJ 229:139–174, 2015 [待核实]；空间与时间约束联盟 Ramchurn 等, AAMAS 2010 [待核实]；Shapley 值用于贡献归因；分组基线 K-Means（Lloyd, 1982；MacQueen, 1967）与谱聚类（Shi & Malik, 2000；Ng, Jordan, Weiss, 2001；von Luxburg, 2007，均 [待核实页码]）。

**K-Means 与谱聚类作为分组基线的六项局限**：

1. 目标错位：聚类最小化簇内散度，而联盟价值取决于能力互补与任务需求，同质邻近的无人机聚成一簇通常并不构成可执行联盟；
2. 簇数须预设，而联盟数由任务数与需求决定且随时间变化；
3. 欧氏度量忽略 3D 可达性与通信可达性；
4. 硬划分，无大小与能力约束；
5. 集中式计算，难以在受限通信下运行；重新聚类引发成员大范围抖动，应以重组次数度量；
6. 谱聚类需要全局相似度矩阵（`O(n²)` 通信与存储）。

因此二者只应作为"几何分组下界基线"，不是公认最优基线。

**实例库**：缺少公认标准库；CSG 常用合成价值分布（均匀、正态、NDCS、Beta 等，清单 [待核实]）；机器人侧多为自建场景。

**新难点**：联盟价值依赖物理仿真，评估代价高；联盟半径与通信半径耦合；成员失联时联盟应降级而非解散；组队决策与感知 Belief 不一致时，同一联盟被各成员认知为不同成员集合（持续认知分歧）。

### 3.3 多智能体路径规划（PF / MAPF）

**形式化**：图 `G = (V, E)`，k 个智能体各有起点 `s_i` 与终点 `g_i`，每步等待或移动；冲突包括顶点冲突与边（交换）冲突，可选跟随冲突与循环冲突（Stern 等 2019 **[已核]**）。目标为 SOC `Σ_i |π_i|` 或 makespan `max_i |π_i|`；变体含匿名 MAPF、终身 MAPF、k-robust、连续时间与运动学约束。复杂性见 Yu & LaValle, AAAI 2013 [待核实]。

**实例字段**：`map(grid | graph | 3D voxel)`、`agents[{s_i, g_i}]`、`conflict_model`、`cost_type`、`time_limit`、`agent_count`、`kinematics(unit-step | continuous | k-robust)`、`lifelong(task_stream)`。

**指标**：时限内成功率；SOC 与 makespan；次优比 `SUB = SOC / LB`，`LB = Σ_i dist(s_i, g_i)`；运行时间中位数与 95 分位；节点扩展数；终身问题吞吐量 `TP = 完成任务数 / T`；执行鲁棒性（实际执行成本与规划成本之比）。

**基线**

| 类别 | 算法与出处 |
|---|---|
| 优先级与窗口 | WHCA*（Silver, AIIDE 2005 [待核实]） |
| 最优 | CBS（Sharon 等, AIJ 219:40–66, 2015 [待核实页码]）；M*（Wagner & Choset, AIJ 2015 [待核实]）；OD+ID（Standley, AAAI 2010 [待核实]） |
| 有界次优 | ECBS（Barer 等, SoCS 2014 [待核实]）；EECBS（Li, Ruml, Koenig, AAAI 2021 **[已核]**） |
| 优先级搜索 | PBS（Ma 等, AAAI 2019 **[已核]**；不完备、不最优） |
| 规则式与可扩展 | PIBT（Okumura 等, IJCAI 2019 **[已核]**；可完全去中心化）；LaCAM（AAAI 2023 [待核实页码]）；LaCAM*（IJCAI 2023 **[已核]**，随时最终收敛至最优） |
| 大邻域搜索 | MAPF-LNS（IJCAI 2021）、MAPF-LNS2（AAAI 2022）[待核实] |
| 连续时间与运动学 | Hönig 等, ICAPS 2016 [待核实]；Andreychuk 等, IJCAI 2019 [待核实] |
| 鲁棒执行 | Atzmon 等, JAIR 67:549–579, 2020 [待核实]；Ma, Kumar, Koenig, AAAI 2017 [待核实] |
| 终身 | Ma 等, AAMAS 2017 [待核实]；Li 等, AAAI 2021 [待核实] |
| 任务与路径联合 | CBS-TA（Hönig 等, AAMAS 2018 [待核实]） |

**实例库**：MovingAI MAPF Benchmarks（https://movingai.com/benchmarks/mapf/index.html ；33 张地图，各 25 个 even 与 25 个 random 场景，单场景最多 7070 个体；地图来自 Sturtevant, IEEE TCIAIG 4(2):144–148, 2012 [待核实]；许可待核实）；League of Robot Runners（https://www.leagueofrobotrunners.org/ ，细节待核实）；POGEMA（学习型 MAPF 评测，[待核实]）；Flatland（铁路调度）；汇总站 https://mapf.info/ 。

**新难点**：3D 图构造规模爆炸，安全距离（尾流、下洗气流）使冲突须扩展为体积冲突；固定翼不能原地等待，动力学使离散步长假设失效；受限通信使集中式 CBS/EECBS 无法直接运行，需去中心化变体并度量规划消息开销；定位误差使冲突成为概率事件（chance-constrained MAPF）；执行延迟需要 k-robust 或在线重规划。

### 3.4 协同覆盖与搜索（CS）

**形式化**：覆盖控制中区域 `Q ⊂ ℝ^d`、重要度密度 `φ(q)`、代价 `H(P, W) = Σ_i ∫_{W_i} f(‖q − p_i‖) φ(q) dq`；覆盖路径规划求完整覆盖的最短或最少转弯路径；探索最大化已知区域；搜索中目标位置未知、先验 `b_0(x)`，最小化期望发现时间或最大化给定时间内的发现概率。

**实例字段**：`region`、`prior_density`/`target_prior`、`sensor_model(footprint, Pd, Pfa, noise)`、`agents`、`obstacles`/`no_fly`、`energy_budget`、`comm_model`、`termination(coverage_fraction | time)`、`target_count`/`targets_dynamic`。

**指标**：覆盖比 `CR(t) = |∪_i seen_i(t)| / |Q|`；冗余度 `RD = Σ_i |seen_i| / |∪ seen_i| − 1`；覆盖时间 `T_90`；覆盖代价 `H(P)`；Voronoi 平衡；发现概率 `P_d(T)`；期望发现时间；累积未发现概率曲线下面积 `∫_0^T (1 − P_d(t)) dt`；建图 F1/IoU；信息增益 `IG = H(b_t) − H(b_{t+1})`。

**基线**：Lloyd 算法与质心 Voronoi 剖分（Du, Faber, Gunzburger, SIAM Review 41(4):637–676, 1999 [待核实]）；覆盖控制（Cortés, Martínez, Karatas, Bullo, IEEE T-RA 20(2):243–255, 2004 [待核实页码]）；牛耕式分解（Choset & Pignon, 1998 [待核实]；综述 Galceran & Carreras, RAS 61(12):1258–1276, 2013 [待核实]）；frontier 探索（Yamauchi, CIRA 1997 [待核实]）与多机器人协调探索（Burgard 等, IEEE T-RO 21(3):376–386, 2005 [待核实页码]）；信息驱动探索（Bourgault 等, IROS 2002 [待核实]；Hollinger & Sukhatme, IJRR 33(9), 2014 [待核实]）；次模贪心（Nemhauser, Wolsey, Fisher, 1978；Krause, Singh, Guestrin, JMLR 9, 2008 [待核实]），提供 `(1 − 1/e)` 近似保证；搜索理论（Koopman, 1956–57 [待核实]；Stone, 1975）与协同贝叶斯搜索（Bourgault, Furukawa, Durrant-Whyte, IROS 2003 [待核实]）。

**实例库**：缺少统一的覆盖与搜索标准库；室内探索有 Radish 数据集 [待核实]；RoboCup Rescue 仿真联赛为搜救协同的长期基准；DARPA Subterranean Challenge 成果见 JFR 特刊 [待核实]。

**新难点**：建筑遮挡使视域高度非凸，须射线投射或体素遮挡实时计算；覆盖面积与分辨率随高度折中；检测概率依赖距离、角度、光照与目标尺寸，是状态函数而非常数；通信受限使各机 Belief 图不一致，导致重复搜索；能量约束使问题成为带预算的定向越野问题；动态目标使静态覆盖变为持续监视，指标改为最大陈旧度。

### 3.5 分布式共识与信息融合（IF）

**形式化**：图 `G(t) = (V, E(t))`，共识动力学 `ẋ_i = Σ_{j∈N_i} a_ij (x_j − x_i)`，离散形式 `x(k+1) = W x(k)`；融合问题中各节点持有 `(x̂_i, P_i)`，目标是达成一致并保持一致性 `E[(x − x̂)(x − x̂)ᵀ] ≤ P`。

**实例字段**：`graph_process(topology, switching, link_failure_prob)`、`initial_states`/`local_measurements`、`noise_model`、`weights_rule(Metropolis | Laplacian | max-degree)`、`time_delay`、`quantization`、`target_aggregate`。

**指标**：分歧度 `D(k) = ‖x(k) − x̄·1‖₂`；收敛时间 `T_ε`；渐近收敛率 `ρ = max{|λ_2(W)|, |λ_n(W)|}`；NEES `ε_k = (x − x̂)ᵀ P⁻¹ (x − x̂)` 跨独立蒙特卡洛运行（不同外生种子）逐时刻求平均（ANEES）后应落在 χ² 置信区间内（单次运行内的时间平均因误差自相关不满足 χ² 检验的独立性假设）；RMSE；保守度 `tr(P_fused)/tr(P_true)`；每节点每轮字节数；信息重复计数造成的过度自信（NEES 超界比例）。

**基线**：平均共识（Olfati-Saber & Murray, IEEE TAC 49(9):1520–1533, 2004 [待核实页码]；Olfati-Saber, Fax, Murray, Proc. IEEE 95(1), 2007 [待核实]；Jadbabaie, Lin, Morse, 2003；Ren & Beard, 2005）；最优权重（Xiao & Boyd, SCL 53(1):65–78, 2004 [待核实]）；gossip（Kempe, Dobra, Gehrke, FOCS 2003；Boyd 等, IEEE TIT 52(6), 2006 [待核实]）；Covariance Intersection（Julier & Uhlmann, 1997 **[已核]**：`P⁻¹ = ω P₁⁻¹ + (1 − ω) P₂⁻¹`，ω 最小化 `tr(P)` 或 `det(P)`，对未知互相关保持一致；改进有 Split CI、Ellipsoidal Intersection）；分布式 Kalman（Olfati-Saber, CDC 2007 [待核实]；Carli 等, IEEE JSAC 2008 [待核实]；Battistelli & Chisci, Automatica 2014 [待核实]）；去中心化数据融合 channel filter（Grime & Durrant-Whyte, 1994 [待核实]）；协同 SLAM（Kimera-Multi、DOOR-SLAM 等 [待核实]）。

**实例库**：无统一标准实例；以随机图族（Erdős–Rényi、随机几何图、小世界、环、链、星）与标量或向量平均为标准测试；协同 SLAM 数据有 UTIAS MR.CLAM [待核实]。

**新难点**：通信拓扑由遮挡与距离决定，时变、有向且与运动耦合；消息丢失与异步破坏 push-sum 的质量守恒；共享先验与重复观测使双重计数成为主要失真来源，而 CI 又过于保守；带宽限制要求稀疏或量化传输，并须保持压缩后协方差的保守性；需要度量认知分歧（各机 Belief 之间的 KL 散度或 Wasserstein 距离的时间序列）。

### 3.6 协同跟踪与数据关联（TR）

**形式化**：可变数量目标集合 `X_k`，每机观测集合 `Z_k^i`（含虚警 `λ_c` 与漏检 `1 − P_d`）；多个可移动传感器平台联合估计；主动跟踪选择平台运动以最小化目标不确定度；CMOMMT（Parker, Autonomous Robots 12(3), 2002 [待核实]）。

**指标**：RMSE、基数误差；OSPA（Schuhmacher, Vo, Vo, IEEE TSP 56(8), 2008 [待核实页码]）`d_p^(c)(X, Y) = ((1/n)(min_π Σ_i d^(c)(x_i, y_π(i))^p + c^p (n − m)))^{1/p}`；MOTA `1 − (FN + FP + IDSW)/GT`；IDF1；HOTA `√(DetA · AssA)`（Luiten 等, IJCV 2021 [待核实]）；NEES/NIS 区间检验；CMOMMT 覆盖指标；融合延迟与通信开销。

**基线**：全局最近邻（匈牙利）、JPDA（Fortmann 等, 1983 [待核实]）、MHT（Reid, IEEE TAC 1979 [待核实]）、GM-PHD（Vo & Ma, IEEE TSP 2006 [待核实]）、LMB/GLMB（Vo & Vo, IEEE TSP 2013 [待核实]）；航迹融合见 §3.5；主动协同跟踪综述 Robin & Lacroix, Autonomous Robots 40, 2016 [待核实]。

**实例库**：MOTChallenge（https://motchallenge.net/ ）、KITTI Tracking、nuScenes、Waymo Open Dataset、WILDTRACK；协同感知 OPV2V、V2X-Sim、DAIR-V2X、V2V4Real、Where2comm（均 [待核实]）；空中多机协同感知数据集见 `research-platforms.md` §3.4。

**新难点**：定位漂移与时钟偏差使跨平台关联不稳定；俯视与斜视的视角差异使外观关联失败；受限带宽下检测、航迹与图像特征三种层级的取舍；城市几何决定的遮挡可预测，可为主动协同提供先验；对抗或规避型目标与追逃交叉。

### 3.7 编队与避障（FO）

**形式化**：期望相对位置 `{d_i}`、刚性或柔性队形、虚拟结构、领航–跟随；碰撞定义 `‖p_i − p_j‖ < r_i + r_j`。

**指标**：碰撞数、最小间距 `d_min`、成功率；路径长度比 `PLR`、延误；队形误差 `E_form = (1/n) Σ_i ‖(p_i − p_c) − d_i‖`；jerk 积分；死锁率；走廊与交叉口吞吐；计算时间。

**基线**：Boids（Reynolds, SIGGRAPH 1987 [待核实]）；速度障碍（Fiorini & Shiller, IJRR 1998 [待核实]）、RVO（ICRA 2008）、ORCA（van den Berg 等, 2011 **[已核]**；RVO2/RVO2-3D：https://gamma.cs.unc.edu/RVO2/ ）；空中避障（Alonso-Mora 等, Autonomous Robots 2015 [待核实]）；BVC（Zhou 等, RA-L 2017 [待核实]）；最小 snap 与分布式 MPC（Mellinger & Kumar, ICRA 2011；Luis & Schoellig, RA-L 2019；MADER, IEEE T-RO 2022；"Swarm of micro flying robots in the wild", Science Robotics 2022，均 [待核实]）；编队控制（Fax & Murray, IEEE TAC 2004；Oh, Park, Ahn, Automatica 2015 [待核实]）。

**实例库**：圆形互换、对向交换、交叉口、走廊等标准场景；仿真平台 gym-pybullet-drones、Flightmare、Crazyswarm；实物平台 Robotarium [待核实]。

**新难点**：多旋翼下洗气流与推力–姿态耦合使"速度即时可达"假设不成立；感知受限与状态估计噪声破坏 ORCA 的互惠性；通信延迟下轨迹交换式避障的版本一致性；GNSS 退化降低相对定位精度；高密度下的死锁与恢复。

### 3.8 通信感知规划与连通性维护（CC）

**形式化**：通信图 `G(p)` 的边由 `SNR(p_i, p_j) ≥ θ` 决定；代数连通度 `λ_2(L(p))`（Fiedler, 1973 [待核实]）；约束为持续连通、周期连通或 k-连通；任务包括中继部署与保持连通的探索、覆盖、编队与任务分配。

**指标**：连通时间占比 `CT = (1/T) ∫ 1[G(t) 连通] dt`；平均 λ₂；最长断连时间；端到端吞吐、时延、丢包率、投递率 PDR；连通约束带来的完成时间膨胀 `T_conn / T_free`；中继数量与能耗。

**基线**：图论连通控制（Zavlanos, Egerstedt, Pappas, Proc. IEEE 99(9), 2011 [待核实]；Yang 等, Automatica 2010 [待核实]）；性能保证（Hsieh 等, JFR 2008 [待核实]）；周期连通（Hollinger & Singh, IEEE T-RO 2012 [待核实]）；全局规划（Kantaros & Zavlanos, IEEE T-RO 2016 [待核实]）；空地信道（Al-Hourani 等, IEEE WCL 2014；Mozaffari 等, IEEE COMST 2019；3GPP TR 36.777、TR 38.901，均 [待核实]）；Dec-POMDP 通信（Goldman & Zilberstein, JAIR 2004 [待核实]）。

**实例库**：缺少公认基准；常见为自建断连地图（ns-3 加地形）；3GPP 信道模型参数可作为通信档位的规范来源。

**新难点**：LoS/NLoS 概率随高度与位置剧变；运动改变拓扑、拓扑决定可行协同；多机同时广播造成冲突，通信本身成为需调度的资源；连通性维护与避障、覆盖目标冲突；须同时报告理想通信与受限通信下的结果以量化通信约束的影响。

### 3.9 追逃博弈（PE）

**形式化**：离散的图上警察与强盗、搜索数 `s(G)`、可见性模型；连续的微分对策（Isaacs, 1965）；角色参数含追捕者数、逃逸者数、信息结构、速度比 `α = v_e/v_p` 与捕获半径。

**指标**：捕获成功率、平均捕获时间、逃逸者生存率；最小追捕者数；追捕代价；与均衡策略的 exploitability（可计算时）。

**基线**：Parsons, 1978 [待核实]；Nowakowski & Winkler, 1983；Bonato & Nowakowski, AMS 2011 [待核实]；综述 Chung, Hollinger, Isler, Autonomous Robots 31(4), 2011 [待核实]；可见性追逃（Guibas 等, IJCGA 1999 [待核实]）；概率追逃（Vidal 等, IEEE T-RA 2002 [待核实]）；Voronoi 分区围捕（Zhou 等, Automatica 72, 2016 [待核实]）；MPE predator-prey 与 VMAS tag 类场景。

**新难点**：3D 空间多一个自由度，所需追捕者数显著增多；建筑盲区使问题成为部分观测随机博弈；追捕者依赖通信共享对逃逸者的 Belief；成绩只在固定对手池上有效，须版本化对手池；排行榜须同时评追捕侧与逃逸侧（Elo/TrueSkill 或双向矩阵）。

### 3.10 分布式约束优化（DC / DCOP）

**形式化**：元组 `(A, X, D, F, α)`，目标 `argmin_x Σ_{f∈F} f(x_f)`；起源为 DisCSP（Yokoo 等, IEEE TKDE 10(5), 1998 [待核实]）。

**指标**：解代价、相对最优间隙；消息总数与大小（DPOP 为指数大小）、NCCC、循环数；消息丢失下的收敛与质量退化。

**基线**：完备算法 ADOPT（Modi 等, AIJ 2005 [待核实]）、BnB-ADOPT（Yeoh 等, JAIR 2010 [待核实]）、DPOP（Petcu & Faltings, IJCAI 2005 [待核实]）；不完备算法 DSA、MGM（Maheswaran 等, 2004 [待核实]）、Max-Sum（Farinelli 等, AAMAS 2008 [待核实]）、k-最优；综述 Fioretto, Pontelli, Yeoh, JAIR 61, 2018 [待核实]；移动传感 DCOP（Zivan 等, JAAMAS 2015 [待核实]）。

**实例库**：随机图着色、随机 DCOP、会议调度、传感器网络、智能电网等生成器；工具 FRODO（https://frodo-ai.tech/ ）与 pyDCOP（https://github.com/Orange-OpenSource/pyDcop ，已归档）；缺少统一公共实例仓库。

**新难点**：约束图由通信与感知范围实时诱导（动态 DCOP）；代价函数来自物理仿真，评估昂贵且有噪声；带环图上 Max-Sum 在丢包下收敛性无保证，需阻尼与终止准则；控制周期内迭代次数有限，应度量固定迭代预算下的 anytime 曲线。

### 3.11 多智能体强化学习（RL / MARL）

**形式化**：Dec-POMDP `⟨I, S, {A_i}, T, R, {Ω_i}, O, h, γ⟩`（Bernstein 等, MOR 27(4), 2002 [待核实]；Oliehoek & Amato, Springer 2016）；一般和情形为 Markov Game 或 POSG；范式含集中训练分散执行（CTDE）、完全分散与参数共享。

**指标**：平均回报、胜率或成功率；样本效率；IQM、最优性间隙与性能剖面（rliable）；对未见场景、队友规模与队友策略的零样本泛化；与独立学习基线的差值；通信量。

**基线**：IQL（Tan, ICML 1993；Tampuu 等, PLoS ONE 2017 [待核实]）；值分解 VDN、QMIX、QTRAN、QPLEX（均 [待核实]）；策略梯度 MADDPG、COMA；MAPPO/IPPO（Yu 等 **[已核]**）；HATRPO/HAPPO（Kuba 等 **[已核]**）；通信学习 DIAL/RIAL、CommNet、TarMAC、IC3Net、SchedNet（均 [待核实]）；评测综述 Papoudakis 等, NeurIPS 2021 D&B [待核实]。

**实例库**：SMAC 与 SMACv2、MPE、Google Research Football、Hanabi、Overcooked-AI、Melting Pot、MA-MuJoCo、VMAS、PettingZoo、JaxMARL、BenchMARL（平台细节见 `research-platforms.md`）。

**新难点**：部分观测程度由传感器几何与遮挡决定，奖励稀疏、回合长；可变规模与类型的智能体集合需要置换不变结构，并评测对智能体数的泛化；训练网络档与测试网络档不同时的鲁棒性；以真值观测训练、以含噪观测评测时的退化；强制多种子、固定训练预算与统计检验。

### 3.12 LLM 多智能体协同（LM）

**形式化**：每个智能体由 LLM 驱动（感知、记忆、通信、规划、执行模块），通信为自然语言或结构化消息；架构有集中式、分散式与混合；低层动作通常由技能库或传统规划器执行。

**指标**：成功率；效率（步数或相对步数）；通信成本（轮数、token、消息条数）与调用成本；冗余动作比例；计划被执行器接受的比例；与 MILP 或匈牙利最优分配的间隙；提示扰动与队友故障下的退化。

**基线**：CoELA（Zhang 等, ICLR 2024 **[已核]**，五模块架构，在 C-WAH 与 TDW-MAT 上评测）；RoCo（ICRA 2024 [待核实]）；SMART-LLM（IROS 2024 [待核实]）；集中式与分散式对比（Chen 等, ICRA 2024 [待核实]）；通用框架 CAMEL、AutoGen、MetaGPT、Generative Agents、多智能体辩论（均 [待核实]）；对照基线为 MILP、PDDL 规划、匈牙利或拍卖、MARL 策略。

**实例库**：Watch-And-Help、VirtualHome、C-WAH 与 TDW-MAT、RoCoBench、Overcooked-AI、Habitat 3.0；MultiAgentBench、LLM-Coordination、Collab-Overcooked、EmbodiedBench；失败模式研究 "Why do multi-agent LLM systems fail?"（均 [待核实]）。

**新难点**：同名模型随时间漂移，须记录模型制品、日期、温度与提示哈希，并提供响应缓存回放；LLM 决策为秒级、控制为毫秒级，须分层并区分仿真时间与墙钟计费；统一 token 与调用预算；3D 几何与可达性推理易出错，须评测几何接地能力；以字节或 token 计的带宽预算下评测压缩与结构化消息的收益；提示注入可经共享消息在智能体间传播，须有红队场景。

## 5. 共性规律及对平台设计的含义

1. **理想化假设可调化**：各族的理想化基准都隐含真值观测、可靠通信与抽象动力学三项假设；将其做成观测、网络、物理三条独立配置轴，可在同一实例上度量理想与现实之间的差距。
2. **协作贡献以干预对照度量**：每个族都应定义"无协同参考"（零通信、同资源包、静态分区加单机策略）与"合法信息的集中式参考"；在共同随机数下以配对差值报告，而不是以比值归一化。跨族只汇总配对差值与支配分层等级，不混合绝对量纲。
3. **问题族之间是流水线关系**：真实系统是"感知 → 融合 → 分配与联盟 → 路径规划 → 避障 → 通信"的组合；除单族评测外，需要组合族评测端到端表现，并支持模块替换（算法隔离模式与闭环模式）。
4. **去中心化与通信开销是一等指标**：排行榜对每个算法同时公布字节数与解质量，以资源–效用支配分层呈现，替代"效用除以字节"类标量。
5. **学习型与 LLM 方法需要回放与预算协议**：LLM 类提供固定模型制品、响应缓存回放与多次重复；RL 类提供固定训练预算与训练种子方差报告。

## 6. 标准问题库（CAPL）的组织方式

### 6.1 五个正交维度

| 维度 | 取值 | 说明 |
|---|---|---|
| 问题族 F | TA、CF、PF、CS、IF、TR、FO、CC、PE、DC、RL、LM | §3 |
| 难度 d | `d0` 教学（可手算或穷举）、`d1` 基础（与文献标准一致）、`d2` 标准（含动态事件与受限网络）、`d3` 困难（含异构、资源争用、失效或对抗）、`d4` 极限（近容量上界） | 由客观旋钮定义：PF 以智能体密度 `k/|V_free|`，TA 以任务/智能体比与约束紧度，CS 以遮挡率与预算比；档名小写，以免与版本名混淆 |
| 规模 n | `n ∈ {4, 8, 16, 32, 64, 128, 256+}` | 任务数与区域面积同步缩放以保持密度；每档规定算力预算 |
| 网络档 | 零通信、理想、参数化受限（范围、丢包、时延、带宽、队列）、网络仿真器级 | D4 对应 `none@1`、`ideal@1`、`abstract-*@1`、`ns3@1` |
| 保真度 | 观测（真值至渲染传感器与噪声）× 物理（质点运动学至含空气动力学与控制器） | D4 采用观测、物理、网络三轴独立命名，不使用数字别名 |

实例标识建议：`capl:<family>/<name>/d<k>/n<S>@<version>`，网络档与保真度作为运行配置与赛道条件记录，不嵌入实例 id，以便同一实例在多档下配对运行。

### 6.2 实例包结构

```
capl-instance/
  manifest.json        # id、族、维度坐标、版本、种子集合、许可、校验和
  world/               # 世界包或引用
  tape/                # Canonical Event Tape（外生事件，固定）
  agents.json          # 智能体配置与能力
  tasks.json           # 任务、目标与需求
  comm.json            # 网络档参数
  sensing.json         # 观测档参数
  objective.json       # 主、次指标与约束
  reference/           # 参考解与下界、最佳已知解、求解器配置（如 MILP 模型）
  baselines/           # 各基线的结果与成绩
  eval/                # 指标实现与单元测试
```

### 6.3 评测规则

- **实例集划分**：公开开发集、验证集（输入公开、真值不公开）、留出集（榜单唯一来源）、扰动集；以秘密种子与生成族隔离防止过拟合。
- **参考解治理**：每个实例标注 `J*`（证明最优）或 BKS（最佳已知）及来源与时间；BKS 被刷新时发布新版本，旧成绩保留并标注。
- **聚合**：实例内以层次自助法汇总，跨实例用性能剖面与 IQM 作为辅助视图；排名键为每个 Suite 唯一的主效用。
- **可复现性**：固定种子、事件磁带、容器镜像摘要；LLM 类强制记录模型制品与响应缓存。
- **防作弊**：评测器之外不可访问世界真值；指标实现固定，禁止由提交方自报。

### 6.4 与公开基准对齐的锚点实例

为保证外部可比性，每族保留若干锚点实例（可比性层）并标注来源：

| 族 | 锚点 |
|---|---|
| PF | MovingAI 的 random-32-32-20、warehouse、Paris/Berlin 等地图，使 LaCAM*、EECBS 等外部成绩可直接对照 |
| TA | Solomon / CVRPLIB 子集的无人机化转换（须声明转换规则） |
| RL | 与 PettingZoo/MPE 兼容的 simple_spread 与 predator-prey |
| IF | 标准随机图族上的平均共识 |
| LM | C-WAH/TDW-MAT 任务模板（许可待核实） |

锚点实例的作用等同于聚类研究中的 Iris：低成本、被公认，用于验证实现正确性与回归测试。

## 7. 与 D4 首批 Benchmark Suite 的对应

| D4 Suite | 问题族 | 主指标（概要） | 代表基线 | 阶段 |

选择依据：首发三族覆盖"分配—搜索—融合"三个基础环节，且各自具备清晰的独立参考与集中式参考；S2 承接 D3 的跨平台交接任务，保持连续性；CF 并入 TA 的高阶层，避免首发时出现四个各自独立的课题而使"成功"的定义不一致。

## 8. 风险与待决策事项

1. **许可与再分发**：MovingAI、CVRPLIB、C-WAH 等外部实例的许可须逐项确认。
2. **最佳已知解的获取成本**：3D 问题的最优解难以计算，约定"可证明下界 + 最佳已知"两层。
3. **指标可比性**：同一族内指标实现固定，禁止提交方自报。
4. **转换的有效性**：2D 基准迁移到 3D 城市可能改变难度属性，须以客观难度量重新标定，并在锚点实例中保留原始 2D 版本。
5. **LLM 类成本与稳定性**：评测预算高，缺省使用缓存回放与抽样评测。
6. **基线实现保真度**：每个基线附论文来源、参数与复现差异说明；未复现到原文水平的须明示。
