# D2.1 需求原文（用户，2026-10-05，D2 实现期间追加）

> 原样保存用户追加需求，作为 D2.1 设计与验收的追溯源。唯一改动：用户给出的“全功能身份口令”明文**不写入本文件与仓库**，以 `<内部口令，仅部署于 emax 服务器密钥文件>` 代替；口令只在部署时写入服务器 `/etc/anet-drone4d/` 下的密钥文件，由服务端比对。

继续完成你的任务，在系统前端增加如下几个需求：

- demo页面载入时要显示版本号，进度条，由于demo系统对于emax服务器的压力问题，使demo系统同时只支持不超过若干个实例用户使用，多的用户要排队等待，载入的时候就要能看到可能要排队。已经访问的用户，如果若干分钟没有操作，则收回服务端的开销，改为只在浏览器端渲染，相当于进入某种节能省电模式，用户操作后重新刷新渲染，并且可能要排队。
- 适配移动端手机端、以及平板操控，后续会使用平板电脑作为沙盘操作遥控指挥器，手机可能进一步简化操作进行指示，手机可能会支持切换窗口之类的，请你自行设计移动端适配。
- demo系统默认的展示功能不变，但如果用户想要进行全功能使用或者操作，在设置里藏一个切换身份的入口，要求输入token口令，口令就是 <内部口令，仅部署于 emax 服务器密钥文件>，输入后就可以使用全部能，这是给我们自己用的。

另外提醒一下，待识别物的感知能力需要量化，比如分贝、比如飞行器在其视野内的分辨率（飞行器尺寸，距离），感知应该有一个类似球形散点的感觉，飞行器的某一个指标可能会切换不同视图，比如声音视图，飞行器就会形成一个递减的辐射场。请你继续完善这些设计并完整实现功能。
