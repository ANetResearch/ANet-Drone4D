D4 把 ANet-Drone4D 扩展为多智能体协同实验平台：以确定性实验内核、实验内交互网络、协同算法接口、标准问题库（Benchmark Suite）、评测与统计框架、可复现 trace 与研究者 SDK 为基础，提供协作智能排行榜（Collaborative Intelligence Leaderboard）。设计由 AWR-06 与 14 份成员文件构成，统称 D4 设计文档集。

## 3. 定义方原则

同一事项只在一个文件中定义，其他文件引用而不重述（AWR-06 XR-01）：

| 事项 | 定义方 |
|---|---|
| 契约字段、类型与编码 | 契约草案 |
| 模块行为、接口签名与模块内算法 | 对应模块 PRD（M28–M34） |
| Suite 的定义、指标、基线与验收 | Suite 规格（S1、S2、S3）与 X1 协议 |
| 排行榜运营与治理 | 排行榜规格 |
| 首篇论文的实验设计 | r04 |
| 原则、跨模块规则、路线图、工作包、发布门禁与 ADR | AWR-06 |

AWR-06 §4.2、§7、§8.6、§9.2 中与上述定义方重叠的内容是概要，二者不一致时以定义方为准。定义方之间的冲突由 AWR-06 §0.5 裁定；§0.5 未裁定的，登记到 WP-D4-01 的实验契约 RFC 中裁定。
