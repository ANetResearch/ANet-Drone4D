# 共享展示

共享展示是一个只读会话：所有访客观看同一个持续运行的仿真，不占用沙盒槽位。公开实例的落地页上，"进入共享展示"打开
`/world/synthcity` 的共享展示；本机 `make run` 启动的也是共享展示（运行档 `demo`）。

## 运行内容

| 部署 | 世界与剧本 | 内容 |
|---|---|---|
| 公开实例 | ANet Synthetic City，剧本 S7 | 区域值守：2 个机巢（机巢箱与垂起起降台）、6 架 P600 与 2 架 AWR-V1，执行 `area_guard` 任务；区域内 2 个行人与 1 辆车，发现后转入 7×24 接力监控。仿真日历按 Asia/Shanghai 时区与真实时间同步，昼夜随之变化 |
| 本机，无六城数据 | ANet Synthetic City，剧本 S0 | 全景展示：七架 P600 螺旋扫描 318 m 的 ANet Tower、两架覆盖街区、三架以 V 形编队沿河巡航，天气由晴转小雨再转雾 |
| 本机，已构建六城 | 深圳，剧本 S1 | 两架 P600 在 6 m/s 的东南风中沿最高塔楼的立面螺旋下降 |

本机可以用 `AWR_WORLD` 与 `AWR_SCENARIO` 指定世界与剧本，例如 `AWR_WORLD=synthcity AWR_SCENARIO=s0-synthcity-showcase make run`。
其余内置剧本包括 S2 上海编队、S3 纽约搜救（智能体协作）、S4 芝加哥湖岸、S5 旧金山地形跟随与 S6 苏州走廊。

## 可用的交互

共享展示中的交互只在浏览器端执行或只读订阅，满员排队期间同样可用：

| 交互 | 说明 |
|---|---|
| 相机 | 自由、跟随、第三人称与 FPV 视角；点选无人机后跟随，焦点无人机走低延迟通道 |
| 传感器视图 | 任意无人机的 FPV，以及日视、夜视与热像三种传感器视图；HUD 显示对视锥内最近识别物的像素进度 `N_eff / N_req` 与当前限制因素 |
| 识别物 | 列表与详情（只读）；敏感范围可在"配置体"与"对选中机型的有效体"之间切换显示 |
| 接力统计 | 覆盖率、监视间隙、被发现次数与交接次数 |
| 机型目录 | 机型卡片与参数表；参考机型标注为模拟参考值 |
| GSD 计算器 | 选择机型、传感器、焦距、识别物类别与距离，即时给出地面采样距离、关键维度上的像素数、各级概率与可行窗口 |
| 场视图 | 视口工具条切换声学、视觉、热与雷达的辐射场显示（见 {doc}`targets`） |
| 时间轴 | 共享展示的时钟由服务器统一推进，访客不能暂停或改变倍速 |

角色徽标显示"公开演示 · 只读"。需要放置无人机、识别物或下发任务时，开启自己的沙盒（{doc}`sandbox`）。

## 其他六座城市：各自的模拟监测展示

在共享展示运行的世界之外打开 `/world/<id>` 时，若该世界属于 UrbanScene3D 六城（例如 `/world/shanghai`），页面播放该城市**自己的**
模拟无人机监测展示：该城市自己的机队、机巢、识别物与任务编排，按该城市的几何生成并验证后一次性录制，再在浏览器端循环回放；该展示
不建立实时连接，角色徽标显示"模拟回放 · 只读"并提示这是离线录制，仍需开启自己的沙盒才能在该城市下发指令。本机若某世界没有打包展示
录制（例如世界包已构建但未附带录制），则回退为**静态浏览**：只加载点云与地形。七个世界的 id 为 `synthcity`、`shenzhen`、`shanghai`、
`newyork`、`sanfrancisco`、`suzhou` 与 `chicago`。

## 观看席位与排队

实时观看连接受席位上限约束（公开实例为 24 个），满员时访客进入观看排队并看到位次与预计等待时间；静态浏览、城市自己的模拟回放、
落地页与节能中的访客不占席位。页面无交互 5 min（席位已满且有人排队时为 2 min）或隐藏 60 s 后进入节能模式：关闭实时连接、保留最后画面、释放席位，
任一交互后重新连接。

## 渲染与画质

点云、天气与界面在浏览器中渲染。画质控制器根据实测帧时间调节点预算，并在 7 档画质之间换档；同一个世界既能在软件渲染器上运行，
也能在桌面 GPU 上运行，画面清晰度与帧率取决于访客设备。
