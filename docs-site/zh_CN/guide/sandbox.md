# 沙盒

沙盒是每位访客独占的隔离会话：拥有独立的 sim-core 进程，可以放置无人机、识别物与机巢，下发任务，接管手动控制并切换传感器视图。
界面与开放接口同权，每条命令都经过相同的准入与安全检查。

## 开启沙盒

| 入口 | 方式 |
|---|---|
| 公开实例 | 落地页"开启我的沙盒"：选择世界与场景模板（缺省为 ANet Synthetic City 与 T5 区域值守），确认后进入 `/sandbox/<sid>` |
| 开放接口 | `POST /api/sandbox/v1/sessions`，或 SDK 的 `Sandbox.create(world, template)`（见 {doc}`../api/sdk`） |
| 本机 | `AWR_PROFILE=sandbox make run` 启动沙盒控制面，SDK 连接 `http://127.0.0.1:8002`（见 {doc}`../intro/quickstart`） |

满员时请求进入排队：界面显示非模态排队卡片（位次、预计等待与离开队列），SDK 以长轮询自动等待并在轮到时认领空位。排队期间可以继续观看共享展示。
公开实例在需要时要求一次工作量证明（浏览器与 SDK 自动求解），并按地址前缀限制会话与排队票的数量。

## 场景模板

每个世界有一套经过验证的场景模板，机巢位置、任务区域与识别物位置均按该世界的几何与视线预先校核：

| 模板 | 内容 | 首次反馈 |
|---|---|---|
| T1 定点巡航 `t1_point_watch` | 1 个机巢箱、2 架 P600，定点悬停并以云台锁定 1 个静止的人 | 约 40 s 明确捕获 |
| T2 多点巡线 `t2_polyline` | 1 架 P600 沿四个航点循环巡线 | 航段与 FPV |
| T3 多机区域巡查 `t3_area_patrol` | 2 个机巢箱、3 架（P600 与 AWR-Q1）分区巡查，区内 3 个游走的人 | 子区与检测 |
| T4 GSD 完整扫描 `t4_scan_gsd` | 1 个机巢、4 架 P600，先预览分配再执行按 GSD 的完整扫描 | 架数与完工曲线 |
| T5 区域值守与接力 `t5_area_guard`（缺省） | 机巢箱与垂起起降台、P600 与 AWR-V1、2 个识别物，`area_guard` 发现后转入接力 | 会话开始后约 60 s 内首次明确捕获 |
| T6 手动飞行与传感器视图 `t6_manual` | 1 架已起飞的 P600、1 个识别物，可选夜间日历 | 接管提示 |

会话条中的"载入场景"可在会话内重新装配任一模板。首次进入沙盒时，4 步引导依次介绍会话条与寿命、识别物面板与敏感范围、任务面板与分配预览、
捕获提示与 FPV，可以跳过。

## 界面

沙盒视图沿用共享展示的浮层式布局，角色徽标为"我的沙盒 · 可操作"。顶栏下方的**会话条**显示世界、剩余寿命（可续期时显示"续期"）、
倍速（受限时标注本会话可达的倍速与原因）、机、识别物与机巢计数，以及"载入场景""重置""结束会话"。四个管理面板：

| 面板 | 内容 |
|---|---|
| 机队 | 机型目录与参数表、克隆编辑、实例增删改、传感器挂载与参数（带边界校验，即时提示 GSD、最大识别距离与可行窗口） |
| 识别物 | 按类别模板新增；在底图点选放置、拖动、画路径与游走区域；属性表单；敏感范围三维显示；感知态与被发现计数 |
| 机巢 | 放置、类型、库存、能量模式、充电通道与电池队列、起降队列 |
| 任务 | 视口工具条绘制点、折线与多边形；类型与参数；"预览分配"；启动、暂停、取消；接力统计 |

面板支持 URL 深链 `?panel=<id>`，可以分享与收藏。

## 会话上限

| 项 | 上限 |
|---|---|
| 无人机 | 12 架 |
| 识别物 | 30 个（每个至多 4 个敏感范围，会话内启用的敏感范围至多 64 个） |
| 机巢 | 4 个 |
| 同时运行的任务 | 6 个 |
| 克隆机型 | 8 个 |
| 配置快照 | 512 KiB |
| 实时连接 | 每会话 4 条 |

任务的输入规模另有配额（面积不超过 1 km²、顶点不超过 64 个、条带不超过 200 条、工作项不超过 50 个等），超出以原因码 585 拒绝。

## 时钟与倍速

会话就绪后时钟以 ×1 启动。倍速档为 ×0.25、×0.5、×1、×2、×5 与 ×10；申请的倍速只在 CPU 预算内授予，受限时返回实际授予值与原因
（例如容量阶梯或单步耗时）。时钟操作为播放、暂停、倍速与单步，经 `POST /sessions/{sid}/clock` 或 SDK 的 `Session.clock()`。
接管手动控制期间时钟锁定为 ×1。

## 手动控制

选中无人机后"接管"即申请租约：任务编排对该机的租约被抢占，其工作项重新分配。

| 输入 | 作用 |
|---|---|
| W / S | 前进、后退 |
| A / D | 左移、右移 |
| Q / E | 下降、上升 |
| 左右方向键 | 偏航 |
| C | 切换速度档（慢、常、快） |
| Esc | 退出接管 |
| Shift+R、Shift+L、Shift+X | 返航、降落、安全停止（全局安全热键，接管期间保持有效） |

触屏与鼠标可以使用虚拟双摇杆；松开即发送停止。固定翼的输入映射为空速、转弯率与爬升率。速度设定点以至多 50 Hz 发送。

手动飞行时始终显示禁入体；预测 3 s 内将进入任一敏感范围时给出警告。软围栏由服务端执行：sim-core 在速度设定点入口把朝敏感范围方向的
速度分量钳为 0，并返回警告 `KEEPOUT_CLAMPED`。界面、SDK 与 REST 的速度控制受同一保护；会话参数 `keepout_guard` 缺省开启，可在设置中关闭，
关闭后进入敏感范围即按判据计为被发现。释放接管后，该机回到可用池，或点击"返回机巢"。

## 快照、重置与切换底图

- **配置快照**：`GET /sessions/{sid}/snapshot` 导出当前的机巢、机队、识别物与任务配置（JSON，至多 512 KiB），会话结束后 10 min 内仍可取回；
  `POST /sessions/{sid}/restore` 在**同一世界**恢复。
- **重置**：重新装配当前模板。
- **切换底图**：`POST /sessions/{sid}/world` 在新世界重启 sim-core，并载入目标世界的同名场景模板。sid 不变，实时连接以关闭码 1012 断开后
  按新世界重连。上一世界的识别物、机巢、任务与视野配置不搬运到新世界（各世界的坐标与几何互不相同）；需要保留时先导出快照。

已知问题：在当前公开实例运行的 0.2.0 版本中，这一隔离并不是在所有切换路径上都成立。部分客户端缓存（识别物、感知与场读数、任务编排、
机群名册、时间轴）此前未按世界重置，导致切换后上一世界的实体与视野配置可能仍然可见，在沙盒会话内切换底图时同样如此。该缺陷已在开发
分支修复（这些缓存现在统一由按世界作用域重置的数据层闸门管理），将随下一版本发布；公开实例重新部署前，仍可能观察到该现象。

## 寿命、续期与节能

| 项 | 规则 |
|---|---|
| 初始寿命 | 30 min |
| 续期 | 每次延长 30 min，至多 120 min；有访客排队时暂停续期 |
| 节能驻留 | 无交互 10 min（沙盒队列非空时 5 min）或页面隐藏后：checkpoint 与配置快照落盘，停止 sim-core、释放槽位；仿真时间与寿命冻结 |
| 无连接空闲 | 只用 REST、没有实时连接的会话，120 s（队列非空时 60 s）内无任何会话内调用即被驻留 |
| 恢复 | 任一交互或会话请求即从 checkpoint 恢复（满员时按恢复票排队）；驻留会话保留 60 min |
| 结束 | "结束会话"、关闭页面、寿命到期或被回收；结束前导出配置快照 |

## 容量

并发沙盒数由容量模型按实测会话成本与 CPU 预算计算，硬上限 6；公开实例当前上限为 2，其余访客排队。落地页与启动屏显示实时观看、沙盒槽位、
排队人数与预计等待时间（公开接口 `GET /api/sandbox/v1/capacity`）。
