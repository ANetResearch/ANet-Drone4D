# 手机与平板

共享展示与沙盒在桌面、平板与手机上均可使用。界面按设备档重排布局，切换设备档或旋转屏幕时只重排布局，不重建视口与实时连接，
选中的实体、相机与面板状态保留。

## 设备档

| 档 | 判定（CSS 像素，随旋转重新判定） | 布局 | 输入 |
|---|---|---|---|
| 手机 | 宽 < 768，或短边 < 600（手机横屏） | 单窗口全屏加底部标签栏（横屏时为左侧竖向标签栏） | 触控 |
| 平板 | 768 ≤ 宽 < 1280 且短边 ≥ 600 | 横屏为指挥器布局；竖屏为视口在上、抽屉在下 | 触控；外接键盘时启用桌面快捷键 |
| 桌面 | 宽 ≥ 1280 | 浮层式布局 | 鼠标与键盘；触屏设备上叠加触控增强 |
| 过窄 | 宽 < 360 | 提示旋转设备或放大窗口 | — |

## 平板：横屏指挥器

三维视口为主体，左右为可停靠侧栏：左栏为机群、识别物与机巢列表，右栏为选中实体的详情（传感器与感知读数）。停靠时侧栏挤占视口宽度，
浮动时覆盖在视口之上；拖动栏头可在两种状态之间切换。底部任务条显示任务状态与进度、对选中机生效的快捷指令（前往、悬停、返航、盯防）、
倍速、时间轴与告警计数。手动控制时出现左右两个虚拟摇杆。

竖屏时视口占上部约 60%，下部为可吸附抽屉（25%、50%、90% 三个吸附点），抽屉内分为机群、任务、识别物与详情四页。

## 手机：五个标签

底部标签栏为**视口、机群、任务、识别物、告警**，任一时刻只显示一个窗口，切换时保留各窗口的滚动与选择；离开视口窗口时渲染降至 10 fps。

沙盒操作者在手机上使用**快捷指令**：①选择无人机（列表或视口点选）；②选择指令：前往（在视口点选地面点）、悬停（固定翼为盘旋）、
返航、盯防（选择识别物后创建定点巡航任务，站位与禁入由编排器计算）；③确认将下发的命令。每个指令至多 4 次点按。手机不提供虚拟摇杆，
只读访客的指令按钮隐藏。

## 触控手势

| 手势 | 动作 |
|---|---|
| 单指拖动 | 旋转视角（俯视模式下为平移） |
| 双指捏合 | 缩放（以两指中点为锚） |
| 双指拖动 | 平移 |
| 双指旋转 | 偏航旋转 |
| 长按 500 ms | 上下文菜单：飞往此处、在此放置识别物（沙盒）、测距、复制坐标 |
| 单击 | 选择实体，或在空地处取消选择 |
| 双击 | 聚焦到实体或地面点 |

触控设备上全部交互控件的最小命中区为 44 × 44 CSS 像素。页面缩放保持可用。

## 画质

移动设备按设备档选择画质：

| 项 | 手机 | 平板 |
|---|---|---|
| 目标帧率 | 30 fps | 60 fps，降档时 30 fps |
| 绘制像素上限 | 1.0 MP | 2.0 MP |
| 点云预算 | 50 万点 | 100 万点 |
| 场视图点数 | ≤ 2048 | ≤ 4096 |
| 机群状态订阅 | 5 Hz，选中机 30 Hz | 10 Hz，选中机 30 Hz |

渲染代码按 WebGL2 规范的最低上限设计（例如不依赖浮点渲染目标），在移动 GPU 上同样可以运行。

## 全屏与主屏启动

- 顶栏"全屏"按钮调用浏览器的全屏接口（Android、桌面与 iPadOS）；iPhone 不支持元素全屏时隐藏该按钮，并提示"添加到主屏幕"。
- 站点提供 Web App 清单：添加到主屏幕后以全屏方式启动，起始页为合成演示城市。站点不注册 Service Worker，避免缓存与版本更新冲突。
- 平板指挥器在全屏或主屏启动时可以锁定横屏；手动控制中旋转屏幕不会中断租约。
- 顶栏、标签栏与摇杆按设备的安全区内缩。
