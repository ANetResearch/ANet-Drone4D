# 版本与路线

ANet Drone4D 先打通一条完整链路，再用 Mock 覆盖所有层，然后在接口不变的前提下逐层替换为真实后端。交付以"D"编号的阶段推进：
D1 对应 V0.1，D2（含 D2.1）对应 V0.2-demo，D3 为事件仿真与主动观测基准。

## 已发布

### V0.1（D1）：所有层就位的 World Runtime

六座 UrbanScene3D 城市与合成演示城市、城市级点云流式加载、FleetSim 1 至 1,000 架、安全与任务、L0/L1 环境、录制与回放、进程内 Mock ANet。
验收 38 项中 36 项通过，P0 子项 25 项全部通过；其余 2 项 P1 以已知问题登记。验收报告见
[D1 验收报告（第 6 轮）](https://github.com/ANetResearch/ANet-Drone4D/blob/main/docs/impl/D1-验收报告-第6轮.md)。

### V0.2-demo（D2 与 D2.1）：交互式沙盒与开放接口

2026-10-13 以 0.2.0 发布。主要内容：

- 每位访客一个隔离沙盒，含并发上限与排队；七个世界底图与场景模板 T1 至 T6；
- 识别物管理与感知量化（检测、识别、确认三级与明确捕获）；
- 机巢与贪心编排、按 GSD 的完整扫描、7×24 接力监控与可持续性评估；
- 开放接口（沙盒 REST v1、`awr.rt.v1`、OpenAPI 3.1）与单文件 Python SDK；
- 含固定翼与垂起的机型目录；
- D2.1：版本与进度启动屏、观看席位与沙盒槽位的排队、节能模式、手机与平板布局、内部身份、声学、视觉、热与雷达的场视图。

验收 55 项中 44 项通过、9 项不通过、2 项待线上测量，以已知问题发布，见 {doc}`acceptance`。V0.2-demo 是与 V0.2 主题并行的演示与开放接口切片，
不改变 V0.2 原有的退出标准。

## D3：事件仿真与主动观测基准

D3 定位为 *A World-Grounded Event Simulation and Active Observation Benchmark for Collaborative Aerial Agents*：在同一世界、同一事件下，
比较不同机队策略得到的观测，研究多个自主智能体在部分可观测条件下如何协同决定在何处、何时、以何种方式观测动态世界。D3 的设计已定稿
（[docs/05](https://github.com/ANetResearch/ANet-Drone4D/blob/main/docs/05-D3-设计增补与决策记录.md)），处于实施阶段。

### 设计要点

| 方面 | 要点 |
|---|---|
| 与 D2 的关系 | D2 原样保留为公开交互沙盒；D3 只新增模块，经登记的扩展点与 D2 接合，并以回归门守护 D2 行为不变 |
| 四个权威 | 世界、事件、物理、智能体互不越界；传感器生成服务是位姿与事件磁带的纯函数，所有物理档共用 |
| 世界资产导入（M22） | 摄影测量三角网格经强制的米制尺度、真北与调平标定，派生几何、导航与质量层 |
| 事件运行时（M23） | 以 `drone4d.event.v1` 编译出跨机逐字节一致的事件磁带；第一批四类事件为跨遮挡身份保持、多人交汇与交接、车辆追踪、未知位置目标搜索 |
| 物理后端（M24） | gz-sim 锁步档为缺省物理档与正式成绩的唯一来源；FleetSim 保留为快速档（开发、训练与大规模搜索）；SITL 档只做飞控验证 |
| 传感器生成（M25） | 网格光栅化相机一遍输出 RGB、深度、实例与语义，含卷帘快门、1080p 多机输出与热成像；GPU 逐射线 LiDAR 与逐点时刻；IMU 由物理档比力合成 |
| 智能体观测（M26） | 智能体的唯一观测出口：观测白名单、锁步与决策时延、链路模型、隔离容器；Python SDK 与 3 个基线策略在首个里程碑交付 |
| 基准运行时（M27） | 以 MCAP 为唯一权威帧存储；赛道按事件类型划分，分别报告事件捕获率、事件理解、主动观测效率与协同效率四项指标及其 95% 置信区间 |
| 对外展示 | 排行榜只在内部工作区展示；公开站只读展示样例（事件回放、多机私有视角、数据检视面板），不展示得分比较，不接受提交 |

### 阶段

| 阶段 | 相对周次 | 内容 | 出口 |
|---|---|---|---|
| P-1 前置 | 第 1 至 3 周 | D2 发布与文案复核、扩展点与回归门、契约 1.3.0 草案、关键链路实测 | 回归门通过、契约评审 |
| P0a 最小基准闭环 | 第 4 至 20 周 | 首个米制世界、1 个固定事件、gz-sim 锁步、多机相机与 LiDAR、Python SDK 与 3 个基线策略、评测与内部排行榜原型 | 样例包与原型榜 |
| P0b 基准 v1 | 第 19 至 34 周 | 四类事件、热成像、排行榜 v1 与受邀提交、重建对比、公开站样例 | P0 出口 |
| P1 | 第 35 至 42 周 | 事件编辑器、大模型指挥层、私有地图与协同、gz 交叉验证、相机独立包 | — |
| P2 | 第 43 至 48 周 | SITL 档、交互模式、标定、全世界网格瓦片、协同探索演示 | — |
| P3 | 第 43 至 53 周（与 P2 并行） | 3DGS 外观层（以评估门 G-3DGS 决定进入）、高斯资产工具链、事件族、扩展导出与数据集发布 | — |

每个阶段的退出标准为：该阶段全部阻塞级验收通过，应交付级验收通过率不低于 80%（未通过项有豁免记录），D2 回归门持续通过。
D3 的验收共 68 条有效条目（阻塞 52 条、应交付 16 条）。

## 后续版本主题

| 版本 | 主题 | 主要内容 |
|---|---|---|
| V0.2 | 真实飞控栈进入回路 | 经 MAVSDK 接入 PX4 SIH（至多 8 架）、Prometheus 后端、虚拟 MID-360、任意 PLY 或 LAS 点云导入、Python 版 `awr.rt.v1` 客户端 |
| V0.3 | 环境物理化与规划 | L2 质量守恒风场库、GPU 风场采样、环境高档、B 样条与 ESDF 规划 |
| V0.4 | 环境作用于传感器与动力学 | 相机与 LiDAR 退化、L2 气动力矩、PX4 SITL 锁步、倒带与假设分叉、P600 参数辨识 |
| V0.5 | 真实世界融合 | GPU 重建、带 RTK 的采集会话、重定位、经 Prometheus 接入真实 P600、COPC 与 3D Tiles 导出 |
| V0.6 | 规模化集群 | 三层互避（4D 预约、ORCA-3D）、带电量约束的覆盖路由、OpenFOAM 风场、HITL |
| V0.8 | Visual World 与高保真传感器 | 3DGS LOD 流式加载与点云同帧、3D Tiles 地形、Isaac 传感器后端、动态物体 |
| V1.0 | Physical Multi-Agent World | 真实 ANet（ANetHub 加每机一个 daemon）、断网下的 CBBA、经受信守卫接入大模型与 MCP、异构智能体 |

D3 的部分内容（gz-sim 物理档、SITL 档、网格传感器）提前了上表中相应版本的条目；两者的对应关系以 docs/05 为准。
