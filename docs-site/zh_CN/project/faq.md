# 常见问题

## 运行环境

**服务器需要 GPU 吗？**
不需要。物理、安全、任务、感知与环境都在 CPU 上计算；点云、天气与界面在访客浏览器中渲染。公开实例运行在 4 核、无 GPU 的服务器上。

**支持哪些操作系统？**
服务器只支持 x86-64 Linux（Ubuntu 22.04 或 24.04 经过验证）：共享内存状态环依赖 x86 的内存序。其他系统可以通过虚拟机或远程 Linux 服务器运行，
再经 SSH 端口转发在本地浏览器中访问。浏览器端不限操作系统，只要支持 WebGL2。

**同一台机器能运行多份实例吗？**
可以。为每份实例设置不同的 `AWR_PORT_OFFSET=k`（0 至 31），全部端口平移 `10·k`；与其他负载共用机器时同时设置 `AWR_CPU_PIN=off`。
两项都可以写入各自仓库根目录的 `.env.local`。见 {doc}`../intro/install`。

**首次 `make run` 为什么较慢？**
首次启动要把飞行、规划、覆盖与几何内核编译进 numba 缓存，并执行一次前端生产构建；之后的启动直接使用缓存，通常在 30 s 内就绪。

## 世界与数据

**为什么 `make run` 提示六座城市构建失败？**
没有下载 UrbanScene3D 原始数据时这是预期结果（退出码 4），不影响合成演示城市。需要六城时执行 `make fetch-data && make worlds`，并先阅读数据集条款。

**可以把六城用于商业用途或公开分发吗？**
不可以。UrbanScene3D 的作者只允许非商业使用，并禁止再分发原始数据或其改动版本。本项目自身部署所获得的授权不转授给使用者。合成演示城市不含第三方数据，
可以自由分享。见 {doc}`../topics/worlds`。

**能否导入自己的点云？**
0.2.0 的 ingest 面向内置数据集与合成城市；任意 PLY 或 LAS 点云的导入列在 V0.2 主题中，三角网格资产导入在 D3 中实施。见 {doc}`roadmap`。

## 共享展示与沙盒

**公开实例上为什么要排队？**
并发沙盒数由容量模型按 CPU 预算计算，公开实例当前上限为 2；满员时访客进入排队，可看到位次与预计等待时间。排队期间可以继续观看共享展示。

**切换底图后，原来布置的识别物和任务去哪了？**
切换底图会在新世界重启仿真并载入该世界的同名场景模板；上一世界的识别物、机巢、任务与视野配置不会带入新世界，因为各世界的坐标与几何互不相同。
需要保留配置时，先导出配置快照，之后可在原世界恢复。已知问题：在当前公开实例运行的 0.2.0 版本中，这一隔离并不是在所有切换路径上都成立，
切换后上一世界的实体或视野配置可能仍然可见；该缺陷已在开发分支修复，将随下一版本发布，见 {doc}`../guide/sandbox`。

**画面稀疏或帧率较低怎么办？**
画质控制器会根据实测帧时间降低点预算以维持帧率。没有硬件 GPU 或使用集成显卡时，画面会更稀疏；关闭其他占用 GPU 的页面、改用桌面浏览器或缩小窗口
都可以提升帧率。

**本机能使用沙盒的浏览器界面吗？**
本机 `AWR_PROFILE=sandbox make run` 提供完整的沙盒接口，可用 SDK 操作。浏览器界面需要把 `/api/sandbox/` 路径分流到 sandbox-api（端口 8002），
与公开实例的 nginx 配置相同，见 {doc}`../topics/deployment`。

**会话为什么自动"驻留"了？**
无交互超过阈值（沙盒 10 min，队列非空时 5 min）或只用 REST 且长时间无调用时，会话进入节能驻留：保存到磁盘并释放槽位，仿真时间与寿命冻结。
SDK、脚本等外部客户端对会话接口的调用计为活动：调用持续期间，打开的页面不会进入节能，页面隐藏时也不会驻留会话。
任一交互或会话请求即可恢复，驻留会话保留 60 min。

**仿真中的时间与时区是怎样的？**
沙盒与共享展示有独立的仿真日历（起始时刻与时区），决定太阳位置、照度与昼夜；公开实例的共享展示按 Asia/Shanghai 时区与真实时间同步。
接口中的时间一律为仿真纳秒 `t_sim_ns`，日历以 UTC 时刻加时区给出。

## 接口与 SDK

**SDK 排队时报 `httpx.ReadTimeout`？**
SDK 1.1.0 及更早版本中，排队的长轮询（单次最长 25 s）沿用 `Sandbox()` 的缺省单次请求超时 10 s。1.1.1 起长轮询使用单独的读超时（等待时长加 10 s），缺省配置即可排队；旧版本请在创建时传入 `timeout_s=30`。见 {doc}`../intro/quickstart` 的排错一节。

**为什么创建会话返回 409 `SANDBOX_EXISTS`？**
同一主体与地址前缀已有未结束的会话。持有其令牌时用 `attach()` 接回，否则以 `force_new=True` 新建。

**可以接入自己的智能体或分配算法吗？**
可以。外部程序可以读取分配快照并提交分配计划（`tasking.snapshot()` 与 `tasking.submit()`），或经速度控制与命令接口直接驱动无人机。
所有命令都经过与界面相同的准入与安全检查。真实 ANet 网络的接入列在 V1.0。

**能接入 PX4 或真实无人机吗？**
0.2.0 使用内置的 FleetSim（PX4 风格控制级联，与 PX4 SIH 飞行记录对照）。PX4 SIH、SITL 与经 Prometheus 接入真实 P600 依次列在 V0.2、V0.4 与 V0.5，
D3 的 gz-sim 锁步档与 SITL 档在实施中。见 {doc}`roadmap`。
